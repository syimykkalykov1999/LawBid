## Что это и зачем

Копия для чтения это второй сервер базы, который повторяет основной с задержкой в секунды. Из него приложение читает то, что не страшно показать на пару секунд устаревшим: поиск, профили, ленты. Запись и чтение собственных записей человека всегда идут в основную базу. Так основная база разгружается, когда читающих стало много.

Приложение пользуется копией само, без выкладки: начинает читать, когда копия готова и отстаёт не больше 10 секунд; перестаёт, если отставание больше 30 секунд; если копия исчезла, создаётся, удаляется или сломалась, все чтения тихо идут в основную базу. Пользователь ничего не замечает.

Когда включать: процессор основной базы стабильно высокий, в **Здоровье системы** лампочка «База» жёлтая из-за нагрузки чтения, а не записи. Это первый и самый дешёвый шаг до разделения базы.

## Что понадобится

- Один раз в Terraform: `db_replica_toggle = true` в настройках прода и `apply` владельцем (инструкция «Terraform plan и apply через наши скрипты»). Это добавляет только права приложения на одну копию и роль мониторинга, базу не создаёт.
- Код 2FA из приложения-аутентификатора. Второй админ не нужен.
- Решение о деньгах: пока копия включена, плата за базу удваивается.

## Шаги

1. Откройте в админке **Масштаб** → раздел «База: копия для чтения и разделение таблиц» → карточка **Копия базы для чтения**.
2. Нажмите **Включить**, введите код 2FA. Карточка покажет «Создаётся». AWS создаёт копию того же класса, что основная база сейчас, 15-30 минут.
3. Когда статус станет «Включено», приложение само начнёт читать из копии. На карточке видно отставание в секундах.
4. Статус «Отстаёт»: ничего срочного, чтения уже идут из основной базы. Посмотрите нагрузку записи на основной базе. Если долго не проходит: **Выключить**, потом снова **Включить** (новая копия).
5. Выключить: **Выключить** (код 2FA). Копия удаляется, приложение к этому моменту уже читает из основной базы.
6. Аварийный рубильник без Terraform: переменная окружения `DB_REPLICA_ENABLED=false` (Claude ставит при выкладке), приложение перестаёт смотреть на копию, сама копия остаётся.

## Как проверить

- На **Масштаб** карточка «Копия базы для чтения» показывает «Включено» и отставание в секундах (норма до 10).
- В **Система → Здоровье системы** лампочка «База» зеленеет, нагрузка на основную базу падает в течение часа.
- AWS Console → **RDS → Databases** появился сервер с именем, заканчивающимся на `-readreplica`.
- Поиск и профили открываются как раньше, свои новые сообщения видны сразу (они читаются из основной базы).

## Частые ошибки

- Включили копию кнопкой и одновременно `growth = { rds_read_replicas = 1 }` в Terraform: получится два разных адреса копии. Выбирайте один способ, кнопку рекомендуем.
- Пока есть копия, автомасштабирование базы не меняет размер основной базы (копии нужен такой же лимит соединений). Раз в неделю придёт письмо с причиной `has_replicas`. Размер меняется вручную вместе, попросите Claude.
- Ждёте, что копия ускорит запись: нет, копия помогает только чтению. Медленная запись это инструкция про разделение таблиц или базы.
- Terraform `apply` «удалит копию»: не удалит, Terraform эту копию не знает, она создана кнопкой вне его.
- Копия у второго сервера базы (шарды): копия повторяет только основную базу; у шард-баз копий нет.
