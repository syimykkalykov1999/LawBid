## Что это и зачем

Внутри кейса адвокат может выставить клиенту счёт, попросить подписать документ и обсуждать кейс в комментариях. У каждого инструмента есть настройки: сроки, напоминания, пеня, окно правок. По умолчанию всё выключено или нейтрально — приложение ведёт себя как раньше, пока вы ничего не поменяли. Эта инструкция объясняет, что значит каждая настройка и когда её стоит трогать. Все настройки — в **Система → Настройки**, ключи начинаются на `case_tools.` и `case_comments.`. Любая правка — один код 2FA и запись в журнал.

Важно: оплаты клиент → адвокат внутри приложения нет. «Ссылка на оплату» в счёте — это внешняя ссылка самого адвоката (его сайт, банк, его Stripe-ссылка); приложение только показывает её клиенту. Деньги, полученные вне приложения, адвокат отмечает кнопкой «оплачено»: часть суммы — «частично оплачен», вся — «оплачен». В бухгалтерскую книгу LawBid такие деньги не попадают.

## Что понадобится

- Вход в админку под владельцем, код 2FA.
- Понимание, какие сроки и напоминания вы хотите для адвокатов (можно начать с значений по умолчанию).

## Шаги

### Счета

Статусы счёта: черновик, отправлен, просмотрен, частично оплачен, оплачен, просрочен, аннулирован.

1. `case_tools.invoice_default_due_days` — срок оплаты по умолчанию в днях. 0 = без срока, тогда напоминаний не будет.
2. `case_tools.invoice_reminder_days` — за сколько дней до срока напоминать, список через запятую. По умолчанию `3,0` (за три дня и в день срока).
3. `case_tools.reminders.mode` — напоминания: `off` выключены; `on` включены; `auto` (по умолчанию) — ежедневная задача работает, только если есть открытые счета со сроком или ждущие подписи.
4. `case_tools.reminders.daily_cap` — потолок напоминаний в сутки, по умолчанию 2000 (0 = без потолка). Обработка идёт пачками по 200.
5. `case_tools.invoice_overdue_remind_every_days` — как часто напоминать о просрочке, по умолчанию 7 дней (0 = не напоминать).
6. `case_tools.invoice_late_fee_percent` — пеня за просрочку в процентах, 0 = выключена. **Включайте только если пеня прописана в договоре адвоката с клиентом** (Retainer Agreement), иначе это юридический риск.

### Подписи документов

1. `case_tools.sign_expiry_days` — через сколько дней запрос на подпись истекает, 0 = не истекает. Истёкший запрос помечается «истёк», адвокат может отправить его заново.
2. `case_tools.sign_reminder_every_days` — как часто напоминать тому, кто не подписал, 0 = выключено.
3. `case_tools.sign_max_reminders` — максимум напоминаний, по умолчанию 3.
4. `case_tools.sign_resend_cooldown_minutes` — пауза между ручными повторами отправки, по умолчанию 60 минут.
5. Кто и когда открыл документ, пишется в журнал кейса (первый просмотр каждого) и в сам запрос (последние 50 просмотров). Ничего включать не нужно.

### Комментарии к кейсам

1. `case_comments.edit_window_minutes` — сколько минут автор может править комментарий, по умолчанию 15 (0 = правка выключена).
2. `case_comments.edit_max_edits` — сколько правок разрешено, по умолчанию 5.
3. Каждый прежний текст сохраняется на сервере для юридического аудита. В приложении метка «изменено» пока не показывается (внешний вид заморожен); она уже приходит из API, показать её можно позже отдельным решением.

## Как проверить

- В **Система → Настройки** у изменённого ключа стоит новое значение, в **Система → Журнал** появилась строка об изменении с вашим именем.
- Тестовый адвокат выставляет счёт со сроком — на следующий день из списка `invoice_reminder_days` клиенту приходит напоминание.
- Отправьте тестовый запрос на подпись и не подписывайте: через `sign_reminder_every_days` дней придёт напоминание, после `sign_expiry_days` запрос станет «истёк».
- Напоминания в режиме `auto`: если открытых счетов и подписей нет, ежедневная задача ничего не делает — это нормально, не ошибка.

## Частые ошибки

- Включили пеню `invoice_late_fee_percent` для всех: у адвокатов без пункта о пене в договоре клиенты получат неправомерное начисление. Держите 0, пока юрист не одобрит.
- Поставили `invoice_default_due_days` = 0 и ждёте напоминаний: без срока напоминать нечего.
- `reminders.mode` = `off` «на время» и забыли: напоминания о подписях тоже остановились. Используйте `auto`.
- Ждёте, что деньги по счёту появятся в бухгалтерии LawBid: не появятся, оплата идёт вне приложения, адвокат отмечает её сам.
- Правка комментария не сохраняется: прошло больше `edit_window_minutes` или исчерпаны `edit_max_edits`. Так задумано.
