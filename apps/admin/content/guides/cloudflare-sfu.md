## Что это и зачем

SFU раздаёт видео в групповом звонке: каждый шлёт поток один раз, а Cloudflare рассылает остальным. Без него группа работает только по схеме «каждый с каждым» (до 4 человек) или одним звуком.

## Что понадобится

- Аккаунт Cloudflare (см. инструкцию «Cloudflare: аккаунт и защита входа»).
- Лучше сначала сделать ключ TURN (см. инструкцию «Cloudflare: ключ для звонков (TURN)»).

## Шаги

1. Откройте [dash.cloudflare.com](https://dash.cloudflare.com) и войдите.
2. В левом меню нажмите **Realtime**, затем откройте раздел **Serverless SFU**.
3. Нажмите кнопку создания приложения (**Create Application**) и впишите имя `lawbid-group-calls`.
4. Cloudflare покажет **App ID** и **App Secret**. Скопируйте оба значения в менеджер паролей. Секрет лучше скопировать сразу: повторно его могут не показать.
5. Не отправляйте значения по почте и в мессенджерах: секрет позволяет тратить ваш трафик.

(Не удалось проверить: точное название кнопки создания; в документации написано только «Create an app».)

## Куда вставить в нашей админке

1. «Ключи и сервисы» → карточка **Cloudflare SFU (group video calls)**.
2. Поле «App ID (CLOUDFLARE_SFU_APP_ID)» → вставьте App ID.
3. Поле «App Secret (CLOUDFLARE_SFU_APP_TOKEN)» → вставьте App Secret.
4. «Добавить ключи» → «Сохранить» (код 2FA) → «Проверить» → «Включить».
5. Затем «Настройки» → параметр `calls.video_provider` = `cloudflare`. Пока ключей нет, система не даст его выбрать.
6. Сколько человек в звонке — параметр `calls.sfu_max_participants` (по умолчанию 20).

## Как проверить

- На карточке после «Проверить» зелёная отметка.
- На странице «Запуск» (группа «Звонки») строка «Групповые видео: ключи Cloudflare SFU и проверка» станет зелёной.
- Позвоните в группу из 5 человек: у всех должно быть видео.

## Частые ошибки

- Ввели ключи, но не переключили `calls.video_provider`: звонки пойдут по-старому.
- Если Cloudflare недоступен, группа до 4 человек звонит напрямую, а у большей остаётся только звук. Звонок не отклоняется.
- Помните: Cloudflare технически видит поток, звонок не закрыт сквозным шифрованием.
