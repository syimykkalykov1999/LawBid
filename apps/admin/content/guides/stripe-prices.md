## Что это и зачем

Подписки адвокатов (месяц, год, место помощника, галочка клиента) списываются по ценам Stripe. У цены есть код вида `price_xxx`. Сервер должен знать эти коды.

## Что понадобится

- Боевой ключ Stripe уже добавлен (инструкция «Платежи - боевые ключи Stripe и вебхуки»).
- Решённые суммы. Пример из плана: основатель (founder) $99.

## Шаги

Важно: в нашей админке есть страница **Цены** (**Система** → **Цены**). Если ключ Stripe включён, она сама создаёт цены в Stripe при смене суммы. Коды в карточке Stripe нужны только как запасные. Можно пойти любым из двух путей.

Путь А. Через нашу админку (проще). Откройте **Цены**, задайте суммы и сохраните: Stripe-цена создастся сама. Если админка написала «Stripe пока не принял цену», цена создастся при первой оплате.

Путь Б. Вручную в Stripe:

1. Откройте [dashboard.stripe.com](https://dashboard.stripe.com) и убедитесь, что включён live mode, не sandbox.
2. Нажмите **More** → **Product catalog** → **+Add product**.
3. В поле **Name** напишите `LawBid Lawyer Monthly`. Остальные поля можно оставить. Если работает Stripe Tax, выберите **Tax code**: SaaS (подробнее в инструкции «Stripe Tax - налог с продаж»).
4. Блок цены: **Pricing model** → **Flat-rate pricing** → **Recurring**. Сумма `99.00` USD, **Billing period** → **Monthly**. Для налога выберите, что цена без налога (налог сверху).
5. Нажмите **Add product**. Откройте продукт и скопируйте **Price ID** (`price_xxx`) рядом с ценой.
6. Повторите для годового тарифа: новый продукт `LawBid Prime Yearly`, **Billing period** → **Yearly**, нужная сумма.
7. Повторите для места помощника: продукт `LawBid Assistant Seat`, в **Unit label** впишите `seat`, **Monthly**.
8. Цену нельзя менять после создания. Если сумма поменялась, создайте новую цену, поставьте её ID в админку, а старую заархивируйте (**Archive price**).
9. Сначала можно сделать всё в sandbox и нажать **Copy to live mode** на странице продукта.

## Куда вставить в нашей админке

**Безопасность** → **Ключи и сервисы** → карточка **Stripe**:

- **Monthly price ID (optional)** - месячная цена (в «Цены» это «Адвокат · месяц»).
- **Assistant seat price ID** - цена места помощника.
- **Yearly (Prime) price ID** - годовая цена.

Нажмите **Сохранить** (код 2FA) → **Проверить**.

(Отдельного поля для цены founder $99 в карточке нет. В коде такого тарифа не найдено, поэтому $99 вводится как обычная сумма месячной цены. Если нужен отдельный тариф, уточните у разработчика.)

## Как проверить

1. В **Система** → **Запуск** пункт «Платежи: боевой ключ Stripe и цены» станет зелёным, когда есть боевой ключ и все три ID (месяц, место, год).
2. Если ID заполнены только частично, пункт жёлтый с текстом «цен задано N из 3».

## Частые ошибки

- ID скопирован из sandbox, а ключ боевой: цена не найдётся. Цены sandbox и live разные.
- Вставили `prod_xxx` (ID продукта) вместо `price_xxx`.
- Цена создана без налога сверху, а Stripe Tax включён: налог посчитается внутрь суммы.
