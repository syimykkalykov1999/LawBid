## Что это и зачем

Посты в Поиске («Для вас») и рилсы сейчас расставляет формула: лайки,
комментарии, свежесть, темы человека, подписки. Большие платформы делают
это в два шага: сначала формула отбирает кандидатов, потом обученная
модель расставляет лучших заново под каждого человека. Модель учится на
журнале показов: что человек увидел и что потом сделал (открыл, лайкнул,
сохранил).

Всё уже встроено и выключено. Формула остаётся как запасной вариант и как
контрольная группа теста. Пока модели нет, у всех формула.

## Когда начинать

Журнал показов пишется, пока идёт хоть один тест (настройка
`ranking.events_mode`) или когда она «on». Нужно несколько недель показов:
программа обучения сама скажет «Not enough data yet», если данных мало, и
ничего не создаст.

## Шаги владельца

1. **Первое обучение (на компьютере).** В папке проекта:
   `cd ml/feed-ranker`, затем
   `python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt`
   (на Mac перед этим `brew install libomp`).
2. Запустите обучение на копии базы только для чтения (read replica):
   `python train.py --dsn "<адрес read replica>" --days 30 --out out`.
   Программа напишет две строки: лучше ли модель формулы (NDCG@10) и куда
   положить файлы.
3. **Загрузка в S3.** В AWS Console → S3 → бакет документов → папка
   `ml/feed-ranker/` → **Create folder** с именем версии (например
   `r202612011530`) → **Upload** обоих файлов `model.onnx` и
   `manifest.json` из `out/<версия>/`.
4. **Включение.** Админка → Настройки → «Обученный ранжировщик»:
   - `reco.ranker.model_key` = `ml/feed-ranker/<версия>/model.onnx`;
   - `reco.ranker.mode` = `auto` (тест идёт, только если модель на
     проверке была лучше формулы) или `on`;
   - `reco.ranker.traffic_percent` = 10 для начала.
5. Через неделю сравните группы теста `post_ranker` (model — модель,
   control — формула):
   `python train.py --report --dsn "<адрес read replica>" --days 7`.
   Программа покажет показы, клики и долю кликов в верхних 10 местах с
   интервалом. Если у model доля выше и интервалы не пересекаются,
   поднимайте `reco.ranker.traffic_percent`.
6. **Выключить в любой момент:** `reco.ranker.mode` = `off` — у всех
   сразу формула (за 15 секунд).

## Что проверяется само

- Модель с другим набором признаков или испорченный файл (не совпала
  контрольная сумма) не загружается — у всех формула.
- В режиме `auto`: если модель считает дольше порога
  `reco.ranker.latency_budget_ms`, на 5 минут снова формула.
- Если S3 недоступен, страницы не ждут: формула.

## Как проверить

1. Админка → Здоровье системы: строка ранжировщика зелёная, в ней версия
   модели из `reco.ranker.model_key`.
2. Откройте Поиск → «Для вас» с тестового аккаунта из группы `model`:
   порядок постов отличается от порядка у аккаунта из группы `control`.
3. `python train.py --report --dsn "<адрес read replica>" --days 1` —
   у обеих групп растут показы, у `model` указана версия `ranker:<версия>`.
4. Поставьте `reco.ranker.mode` = `off` — через 15 секунд у всех снова
   порядок по формуле.
