## Что это и зачем

Три вещи, и все они по умолчанию ВЫКЛЮЧЕНЫ, чтобы ничего не стоило денег, пока вы сами не включите.

1. Карточка «Кто больше всех нагружает» на странице Масштаб: топ пользователей, адресов и разделов по запросам, байтам и сообщениям. Нужна, чтобы увидеть, кто съедает сервер.
2. Ежемесячная автоматическая проверка бэкапа (AWS Backup restore testing): первого числа в 14:00 UTC AWS сам поднимает временную базу из свежей копии, замеряет время и удаляет её через час. Если проверка не прошла, звонит телефон.
3. Выгрузки данных идут потоком (страницами), а не в памяти. Это работает всегда, включать ничего не надо; одновременно идут не больше двух выгрузок.

## Что понадобится

- Вход в админку как владелец и код 2FA.
- Доступ к AWS Console и к Terraform на вашем Mac (для пункта 2).

## Шаги

1. Карточка нагрузки: в настройках окружения API задайте `HEAVY_HITTERS_SAMPLE=10` (считается каждый десятый запрос; `0` выключает). Окно списка задаёт `HEAVY_HITTERS_WINDOW_MIN` (по умолчанию 60 минут). Перезапустите API.
2. Откройте в админке **Система → Масштаб**, найдите карточку «Кто больше всех нагружает».
3. Проверка бэкапа: в Terraform поставьте `backup_restore_test_enabled = true`, выполните `terraform plan` и проверьте, что создаются только план проверки, правило EventBridge и цель. Применяйте сами.
4. В AWS Console откройте **AWS Backup → Restore testing** и убедитесь, что план появился.
5. После первого запуска откройте **Система → Здоровье системы**, строка «Учебное восстановление».

## Куда вставить в нашей админке

Ничего вставлять не нужно: переключатели лежат в окружении API и в Terraform, результат виден в админке.

## Как проверить

В карточке на Масштабе появились списки; в строке «Учебное восстановление» после 1-го числа стоит «успешно» и время. Тестовая тревога: AWS Backup → Restore testing, остановить задачу, должно прийти письмо или звонок.

## Частые ошибки

- В карточке написано «Счётчик выключен»: не задан `HEAVY_HITTERS_SAMPLE` больше нуля.
- Проверка падает с «No default subnet»: в Terraform не заполнены подсеть и группа безопасности базы; модуль stack заполняет их сам, проверьте `terraform plan`.
- Временная база осталась после проверки: удалите её в консоли RDS, иначе она платная.
