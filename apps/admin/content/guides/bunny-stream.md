## Что это и зачем

Bunny Stream принимает загруженные видео и рилсы, ужимает их и показывает пользователям. Пока ключей нет, видео не грузятся. После «Включить» они заработают без обновления приложения.

## Что понадобится

- Почта и банковская карта для bunny.net.
- Доступ к админке с правом владельца.

## Шаги

1. Откройте [dash.bunny.net](https://dash.bunny.net) и зарегистрируйтесь (**Sign up**), подтвердите почту.
2. Пополните счёт (**Billing**) на небольшую сумму, например $10: сервис списывает по факту.
3. Слева нажмите **Stream**.
4. Нажмите кнопку добавления библиотеки (**Add Video Library**), имя `lawbid-video`, регион хранения по желанию. Подтвердите.
5. Откройте созданную библиотеку → раздел **API**. Скопируйте оттуда три значения: **Video Library ID** (цифры), **CDN Hostname** (вид `vz-xxxx.b-cdn.net`) и **API Key** (ключ именно этой библиотеки, не аккаунта).
6. Если есть поле **Read-Only API Key**, скопируйте и его: по нему сервер проверяет подпись входящих сообщений Bunny.
7. Откройте вкладку **Security**. Включите защиту ссылок токеном (**Embed View Token Authentication**). В карточке **Token authentication key** скопируйте ключ: это другое значение, не API Key.
8. Токен для вебхука придумывать не нужно: в нашей админке есть кнопка «Сгенерировать».
9. После переезда на боевой сервер откройте в Bunny вкладку **API** библиотеки и впишите адрес вебхука, который покажет карточка в нашей админке.

(Не удалось проверить: точные подписи кнопки создания библиотеки и расположение **Video Library ID** и **CDN Hostname**; официальные страницы их не называют. Здесь взяты из нашей прежней инструкции и сторонних руководств, сверьте на экране.)

## Куда вставить в нашей админке

1. «Ключи и сервисы» → карточка **Bunny Stream (video)**.
2. «Video library ID» → Video Library ID.
3. «CDN hostname» → CDN Hostname (можно с https://, лишнее уберётся).
4. «Library API key» → API Key.
5. «CDN token authentication key» → ключ из шага 7.
6. «Webhook token» → нажмите «Сгенерировать».
7. «Read-only API key» → значение из шага 6 (необязательно, но лучше).
8. «Добавить ключи» → «Сохранить» (код 2FA) → «Проверить» → «Включить».

## Как проверить

- На карточке после «Проверить» зелёная отметка.
- Загрузите короткое видео в приложении: оно должно обработаться и воспроизвестись.
- Отдельной лампы на «Запуск» для Bunny нет. Деньги по Bunny видны на странице «Расходы».

## Видео в постах ленты (флаг video_posts)

Видео прикрепляются не только к рилсам: флаг `video_posts` (Админка → «Функции», сейчас «Выкл») разрешает видео в обычных постах ленты. Пока флаг выключен, такие видео не загружаются и минуты Bunny не растут. Когда его включат, расход Bunny растёт: следите за строкой «Видео (Bunny Stream)» в «Расходы» и лимитом минут в «Лимиты» (`budget.video.monthly_max`). Автоматическая пауза новых загрузок сработает и для постов.

## Частые ошибки

- Вставили API Key аккаунта вместо ключа библиотеки: загрузка не пройдёт.
- Перепутали API Key и ключ токена-защиты: ссылки не будут открываться.
- Не пополнили счёт: сервис остановит загрузку.
