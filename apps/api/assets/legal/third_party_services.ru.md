# Сторонние сервисы

*Черновик, подготовленный для проверки лицензированным юристом США; это не юридическая консультация.*

SiMA LLC (под названием LawBid) использует перечисленных ниже поставщиков услуг для работы Сервиса. Это «поставщики услуг» или «обработчики», которые вправе использовать персональные данные только для оказания услуги нам. Эта страница перечисляет их, чтобы вы видели, кто может получать ваши данные. Как мы обращаемся с персональными данными в целом, объяснено в нашей [Политике конфиденциальности](https://lawbid.dev/privacy).

Список отражает программное обеспечение, которое приложения и серверы LawBid используют сейчас. Поставщики могут обрабатывать данные в США и других странах, где они работают. Мы обновляем эту страницу, когда добавляем или заменяем поставщика.

## Поставщики

### Stripe, Inc.

- **Назначение:** платежи, подписки и выплаты адвокатам (Stripe Connect), включая проверку личности платёжных аккаунтов адвокатов.
- **Какие данные:** имя, email, данные платёжной карты или банка (хранит Stripe, а не LawBid), платёжные реквизиты, документы личности для аккаунтов адвокатов, записи о транзакциях.
- **Сайт:** stripe.com
- **Условия обработки данных:** Stripe Services Agreement и Data Processing Agreement действуют при принятии условий Stripe. Владельцу нужно подтвердить, что аккаунт ими охвачен.

### Twilio Inc.

- **Назначение:** отправка одноразовых кодов подтверждения по SMS.
- **Какие данные:** номер мобильного телефона, содержимое сообщения (код), статус доставки.
- **Сайт:** twilio.com
- **Условия обработки данных:** требуется подтверждение владельца: подписанный DPA не проверен

### Amazon Web Services (AWS), включая Amazon SES и Amazon S3

- **Назначение:** облачный хостинг API и сервисов, хранение файлов и доставка email (Amazon SES) для проверочных и уведомительных писем.
- **Какие данные:** данные аккаунта, загруженные вами контент и файлы, адреса email и содержимое сообщений, журналы серверов и IP-адреса.
- **Сайт:** aws.amazon.com
- **Условия обработки данных:** AWS Customer Agreement и AWS Data Processing Addendum. Владельцу нужно подтвердить, что DPA принят для аккаунта.

### CockroachDB Cloud (Cockroach Labs, Inc.)

- **Назначение:** основная база данных и её резервные копии.
- **Какие данные:** записи об аккаунтах, профилях, кейсах, ставках, сообщениях, отзывах и ссылки на платежи.
- **Сайт:** cockroachlabs.cloud
- **Условия обработки данных:** требуется подтверждение владельца: подписанный DPA не проверен

### Firebase Cloud Messaging (Google LLC)

- **Назначение:** push-уведомления в мобильное приложение.
- **Какие данные:** push-токен устройства, содержимое уведомления, идентификаторы устройства и приложения.
- **Сайт:** firebase.google.com
- **Условия обработки данных:** условия Firebase и Data Processing and Security Terms. Владельцу нужно подтвердить принятие.

### Bunny.net (BunnyWay d.o.o.)

- **Назначение:** хранение, обработка и доставка видео.
- **Какие данные:** загруженные вами видео, метаданные видео, IP-адреса зрителей и журналы запросов.
- **Сайт:** bunny.net
- **Условия обработки данных:** требуется подтверждение владельца: подписанный DPA не проверен

### Sentry (Functional Software, Inc.)

- **Назначение:** мониторинг ошибок и производительности серверного ПО, когда LawBid его включает.
- **Какие данные:** технические отчёты об ошибках, метаданные запросов, идентификаторы серверов и IP-адреса; содержимое кейсов и чатов отправлять не предполагается.
- **Сайт:** sentry.io
- **Условия обработки данных:** требуется подтверждение владельца: подписанный DPA не проверен

### Google Cloud Translation (Google LLC)

- **Назначение:** машинный перевод пользовательского контента между английским и русским, когда пользователь его запрашивает.
- **Какие данные:** текст, который нужно перевести.
- **Сайт:** cloud.google.com
- **Условия обработки данных:** условия Google Cloud и Data Processing Addendum. Владельцу нужно подтвердить принятие.

### Google Sign-In и Sign in with Apple

- **Назначение:** необязательный вход через аккаунт Google или Apple.
- **Какие данные:** подписанный токен с вашим именем, email (или приватным relay-адресом Apple) и идентификатором аккаунта.
- **Сайт:** google.com, apple.com
- **Условия обработки данных:** условия провайдера; LawBid получает только токен, который вы разрешили.

## Соглашения об обработке данных

Мы используем каждого поставщика на его стандартных коммерческих условиях и с соглашением или дополнением об обработке данных там, где поставщик его предлагает. Записи с пометкой «требуется подтверждение владельца» — это случаи, где подписанное или принятое соглашение ещё не проверено; страница будет обновлена после проверки.
