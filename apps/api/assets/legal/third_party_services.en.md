# Third-Party Services

*Draft prepared for review by a licensed US attorney; not legal advice.*

SiMA LLC (doing business as LawBid) uses the service providers below to run the Service. They are “service providers” or “processors” that may use personal data only to provide their service to us. This page lists them so you can see who may receive your data. How we handle personal data overall is explained in our [Privacy Policy](https://lawbid.dev/privacy).

The list reflects the software the LawBid apps and servers use today. Providers may process data in the United States and other countries where they operate. We update this page when we add or replace a provider.

## Providers

### Stripe, Inc.

- **Purpose:** Payments, subscriptions and payouts to attorneys (Stripe Connect), including identity verification of attorney payment accounts.
- **Data involved:** Name, email, payment card or bank details (held by Stripe, not by LawBid), billing details, identity documents for attorney accounts, transaction records.
- **Website:** stripe.com
- **Data processing terms:** Stripe Services Agreement and Data Processing Agreement apply on acceptance of Stripe terms. Owner to confirm the account is covered.

### Twilio Inc.

- **Purpose:** Sending one-time verification codes by SMS.
- **Data involved:** Mobile phone number, message content (the code), delivery status.
- **Website:** twilio.com
- **Data processing terms:** To be confirmed by owner: signed DPA not verified

### Amazon Web Services (AWS), including Amazon SES and Amazon S3

- **Purpose:** Cloud hosting of the API and services, file storage, and email delivery (Amazon SES) for verification and notification emails.
- **Data involved:** Account data, content and files you upload, email addresses and message content, server logs and IP addresses.
- **Website:** aws.amazon.com
- **Data processing terms:** AWS Customer Agreement and AWS Data Processing Addendum. Owner to confirm the DPA is accepted for the account.

### CockroachDB Cloud (Cockroach Labs, Inc.)

- **Purpose:** Primary database and its backups.
- **Data involved:** Account, profile, case, bid, message, review and payment-reference records.
- **Website:** cockroachlabs.cloud
- **Data processing terms:** To be confirmed by owner: signed DPA not verified

### Firebase Cloud Messaging (Google LLC)

- **Purpose:** Push notifications to the mobile app.
- **Data involved:** Device push token, notification content, device and app identifiers.
- **Website:** firebase.google.com
- **Data processing terms:** Firebase terms and Data Processing and Security Terms. Owner to confirm acceptance.

### Bunny.net (BunnyWay d.o.o.)

- **Purpose:** Storage, processing and delivery of videos.
- **Data involved:** Videos you upload, video metadata, viewer IP addresses and request logs.
- **Website:** bunny.net
- **Data processing terms:** To be confirmed by owner: signed DPA not verified

### Sentry (Functional Software, Inc.)

- **Purpose:** Error and performance monitoring of the server software, when enabled by LawBid.
- **Data involved:** Technical error reports, request metadata, server identifiers and IP addresses; no case or chat content is intended to be sent.
- **Website:** sentry.io
- **Data processing terms:** To be confirmed by owner: signed DPA not verified

### Google Cloud Translation (Google LLC)

- **Purpose:** Machine translation of user content between English and Russian, when a user asks for it.
- **Data involved:** The text to be translated.
- **Website:** cloud.google.com
- **Data processing terms:** Google Cloud terms and Data Processing Addendum. Owner to confirm acceptance.

### Google Sign-In and Sign in with Apple

- **Purpose:** Optional sign-in using your Google or Apple account.
- **Data involved:** A signed token with your name, email (or Apple private relay email) and account identifier.
- **Website:** google.com, apple.com
- **Data processing terms:** Provider terms; LawBid receives only the token you authorize.

## Data processing agreements

We use each provider under its standard commercial terms, and a data processing agreement or addendum where the provider offers one. Entries marked “To be confirmed by owner” are items where a signed or accepted agreement has not yet been verified; this page will be updated once it has been.
