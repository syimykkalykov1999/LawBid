# Админка: что вставить руками и как работает «авто» (аудит 02.11.2026)

Цель владельца: ключи и файлы вставляются в админке и работают без правки кода и без выката; режим «авто» сам усиливает и ослабляет.

## Что искали и где

- Все чтения переменных окружения в `apps/api/src` (`process.env.*`, `config.get/getOrThrow`) сверены с реестром ключей админки `apps/api/src/common/secrets/provider-registry.ts`.
- Для каждого поля реестра проверено, что код читает его через `SecretsService` (значение из админки первым, переменная окружения — запасной путь). Обход, при котором вставленное в админке не работало бы, не найден.
- Все настройки со значением `'auto'` в `common/app-settings/app-settings.defaults.ts` (около 40) сверены с кодом, который их читает.
- Мобильные `String.fromEnvironment` в `apps/mobile/lib` сверены с тем, что отдаёт `bootstrap.service.ts`.
- Пересечение с #587 («Три вопроса», поля Firebase Web в админке): не трогалось, чтобы не дублировать.

## 1. Вставить в админке (Интеграции → карточка → «Сохранить» → «Проверить» → «Включить»)

Ключи хранятся зашифрованно, читаются без выката. Эти карточки уже есть:

| Карточка | Что вставить | Файлом |
|---|---|---|
| Firebase Cloud Messaging (пуши) | Project ID, e-mail, закрытый ключ | .json (кнопка уже была) |
| APNs (звонки на iPhone) | Key ID, Team ID, закрытый ключ | **.p8 — новая кнопка** (Key ID берётся из имени файла) |
| Хранилище (S3 / CloudFront) | бакеты, CDN, закрытый ключ CloudFront | **.pem — новая кнопка** |
| GitHub (облако одной кнопкой) | repo, App ID, Installation ID, ключ | **.pem — новая кнопка** |
| Stripe | секретный, публичный ключ, секреты вебхуков | нет (текст) |
| Twilio, SES, Bunny, Google Translate | ключи/адреса | нет |
| TURN, Cloudflare TURN/SFU, LiveKit | ключи | нет |
| OpenSearch, Persona, Turnstile, PagerDuty | ключи | нет |
| Вход Google / Apple, календари Google / Microsoft | id приложений | нет |
| Sentry | DSN API / телефона / админки | нет |
| Cloudflare R2, Rekognition, Amazon Location, Google Places, OpenAI-модерация, PhotoDNA, NCMEC | ключи | нет |

Firebase Web (4 публичных значения для веб-пушей) появится в админке с #587; после его выката владелец вносит значения там же.

Ссылка магазина для кнопки «Обновить» в приложении уже задаётся в админке (`app_config.store_url_ios` / `store_url_android`), пересборка не нужна.

## 2. Не может жить в админке (и почему)

| Что | Почему | Где |
|---|---|---|
| `DATABASE_URL`, `REDIS_URL`, `JWT_KEYS`, `SECRETS_MASTER_KEYS`, `MESSAGE_ENC_KEYS`, `ADMIN_TOTP_ENC_KEY` | нужны серверу раньше, чем он откроет базу админки; мастер-ключи шифруют сам склад ключей | AWS Secrets Manager (Terraform) |
| Роль AWS (S3, SES, KMS без ключей) | выдаётся задаче ECS | Terraform |
| `WITH_FFMPEG` (кадры видео) | ffmpeg ставится в образ при сборке | `gh variable set WITH_FFMPEG --body 1` + Container scan с `with_ffmpeg=true` + деплой, затем в админке `moderation.video.frames_enabled` |
| `google-services.json`, `GoogleService-Info.plist` | зашиваются в приложение при сборке | сборка приложения |
| Секреты App Store Connect / Google Play | нужны CI до запуска приложения | GitHub environment `release` |
| ClamAV | отдельная служба рядом с воркером | Terraform |

## 3. Режимы «выкл / вкл / авто»

Проверено по коду: у всех настроек, чьё значение по умолчанию `auto`, есть читатель, который понимает `auto`; режим «авто» не просто надпись. Примеры, прочитанные целиком: журнал денег (последние N дней каждую ночь, всё раз в неделю), события (база → поток при росте числа событий в сутки), метрики маршрутов (пишет минуту только при 5xx или медленном p95), журнал просмотров файлов (доля из `files.access_log_sample_percent`), разбиение таблиц (по `partition.auto_rows`), «раздутость» базы, обратное заполнение поиска по чатам (только ночью), события ранжирования (только пока есть потребитель), проверка по цене (дневной лимит денег), лимит денег автомасштаба (SSM). Нагрузкой на проде это не проверялось.

Не «авто» по природе: `moderation.video.frames_enabled` (вкл/выкл; нужен ffmpeg в образе, без него проверяется только обложка, ошибка не возникает).

## 4. Что сделано в этом PR

Кнопка «Загрузить файл .p8 / .pem» в карточках APNs, Хранилища и GitHub: файл читается в браузере, текст попадает в поле ключа, Key ID берётся из имени `AuthKey_XXXXXXXXXX.p8`. Раньше файл надо было открывать в текстовом редакторе и копировать.

## 5. Единый список для владельца

1. Админка (2FA) → Интеграции: вставить по карточкам из раздела 1 то, что есть (Stripe, Twilio, Firebase .json, APNs .p8 и т.д.).

3. Видео по кадрам: `gh variable set WITH_FFMPEG --body 1`, Container scan, деплой, затем `moderation.video.frames_enabled`.
4. Terraform (#558, #568) и AWS — отдельно, этим PR не затрагиваются.
