# Защита от ложных жалоб и автомодерация (владелец, 2026-10-27)

## Кратко для владельца (5 строк)

1. Жалоба теперь имеет вес: новый аккаунт, без подтверждённого телефона, с одного устройства или всплеском регистраций почти ничего не весит. Три «куклы» больше не скроют ничей пост.
2. Пост адвоката с галочкой по жалобам не скрывается сам: он попадает в «приоритетную проверку» человеком (настройка; можно включить скрытие при более высокой сумме).
3. Кто часто жалуется зря, получает предупреждение, потом паузу в жалобах (как требует DSA ст. 23); это видно в админке и можно обжаловать. Владельцам контента даём страйки (90 дней) и лимиты: пауза между постами, нельзя публиковать новое, нельзя и комментировать.
4. Система сама ограничивает и блокирует аккаунты по сумме сигналов (вес жалоб + страйки + проверка текста). Человек подключается только по апелляции: «одобрить» возвращает аккаунт, контент и страйки. По умолчанию автомеры по аккаунтам в режиме «Тень» (только пишут в журнал), проверка текста выключена.
5. Всё настраивается в Модерация → Автомодерация (метрики: действий в день, доля апелляций, доля отменённых, тревога при большом проценте отмен). Только 2FA, второй админ не нужен.

## Исследование (источники, проверено 2026-10-25)

- Discourse Meta, «Managing user reputation and flag priorities» (meta.discourse.org/t/123464): жалоба весит по уровню доверия и точности жалобщика (последние 100 жалоб), скрытие по порогу суммы. Взят как образец весов.
- Facebook reporter trust score, 2018 (BGR, 2018-08-21, bgr.com/2018/08/21/facebook-trust-score-measuring-fake-news): вес будущих жалоб растёт, если прошлые подтверждались. Источник старый, это единственный публичный разбор такой оценки у Meta. Свежих (2025–2026) публикаций Meta, Reddit и Discord про вес жалобщика найти не удалось: поиск дал только отчёты о прозрачности без деталей.
- DSA ст. 23 (prighter.com/resources/laws/dsa/articles/article-23; springlex.eu/en/packages/dsa/dsa-regulation/article-23/): сначала предупреждение, потом приостановка обработки явно необоснованных жалоб «на разумный срок», оценка по числу, доле и тяжести, правила описать в условиях. Реализовано как лестница «предупреждение, пауза».
- YouTube, «Community Guidelines strike basics» (support.google.com/youtube/answer/2802032, страница показывает ©2026): первое нарушение предупреждение, страйки живут 90 дней, ограничения 1 и 2 недели, третий страйк может закончиться удалением канала, есть апелляция. Взят срок 90 дней и лестница.
- OpenAI omni-moderation (сводные обзоры 2026; getmaxim.ai/bifrost/model-library/compare/openai/omni-moderation-latest, llmgateway.io/changelog/moderations-flat-request-pricing): бесплатный эндпоинт для текста и картинок; один источник сообщает о плате 0,00001 $ за запрос с 2026-08-07, официально не подтверждено. В любом случае около нуля; страховка: суточный потолок запросов.
- Google Perspective API (perspectiveapi.com): закрывается 2026-12-31, новые заявки не принимаются с февраля 2026. Не выбран.
- AWS Comprehend toxicity (aws.amazon.com/comprehend/pricing; docs.aws.amazon.com/comprehend/latest/dg/comprehend-availability-change.html): платно, единица 100 знаков, минимум 3 единицы за запрос; функция не в списке закрытых для новых клиентов с 2026-04-30. Дороже и требует нового SDK. Оставлено как следующий провайдер (в коде есть шов `TextClassifier`).
- Картинки: уже есть AWS Rekognition + PhotoDNA (раздел «Фото и видео»), не дублируем.

Выбор: OpenAI omni-moderation (бесплатно/копейки, текст, быстро, без нового пакета). Он не покрывает спам, мошенничество и навязывание услуг: это остаётся за правилами (слова, ссылки, повторы). Насилие и преступления по умолчанию не учитываются, потому что юристы о них пишут по работе.

## Как работает

**Вес жалобщика** (`report-weight.ts`): 1 у обычного аккаунта. Новее 7 дней ×0,2; без подтверждённого телефона/почты ×0,5; адвокат с галочкой ×1,5 (потолок 1,5); точность по последним 100 решённым жалобам ×0,1–1,25; всплеск регистраций (3+ аккаунта за 24 ч) ×0,2; один IP/устройство = один жалобщик (считается самый тяжёлый); то же устройство, что у автора, вес 0, та же сеть ×0,5; жалобщик на паузе 0. Скрытие при сумме ≥ `moderation.auto_hide_score` (3). Старый режим: `moderation.auto_hide_mode = count`.

**Адвокат с галочкой**: при достаточной сумме объект не скрывается, жалобы получают флаг `priority_review` (в очереди жалоб метка и фильтр). `moderation.verified_attorney_action = hide` скрывает при `verified_attorney_score` (6).

**Ложные жалобы**: за 30 дней минимум 5 решённых, 80% и больше отклонено, то предупреждение; после него ещё 3 отклонённых подряд, то пауза 7 дней (×2, ×3, ×4 при повторах). Жалоба во время паузы даёт 403 `REPORTING_SUSPENDED`. Апелляция: `POST /moderation/reporting-appeal`, решение в админке.

**Страйки**: удаление модератором = 1 очко (скрытие 0), живёт 90 дней. 3 очка пауза между постами, 5 нельзя публиковать новое, 8 нельзя и комментировать. Сообщения, звонки и свои дела не затрагиваются. Автоскрытие страйков не даёт. Апелляция решения модератора, которую одобрили, снимает страйк. Выключатель `moderation.strikes.enabled`.

**Автомеры по аккаунту** (`moderation.auto.*`): оценка = вес жалобщиков по всему контенту за 30 дней + очки страйков + сильные срабатывания проверки текста. 6 ограничить на 3 дня, 10 приостановить публикации на 7 дней, 15 заблокировать. Адвокатам: только приоритетная проверка человеком, а постоянную блокировку любого адвоката всегда решает человек. Режимы off / shadow / enforce (по умолчанию shadow). Пользователь получает уведомление с причиной и может подать апелляцию (30 дней).

**Апелляции**: одобрение возвращает контент (жалобы по нему закрываются как необоснованные, что бьёт по жалобщикам), аккаунт и страйки. Срок ответа `appeal_sla_hours` (48); при `sla_auto_approve` просроченные одобряются сами, но только если решение было пограничным (оценка меньше порога ×1,25). Задача `moderation.appeal-sla` раз в час.

**Метрики** (`GET /admin/moderation/auto-metrics`, страница Автомодерация): автодействия по дням, тень, апелляции, доля апелляций, доля отменённых, просроченные, тревога, если отменено ≥ `alarm_overturn_percent` (30%) при минимум 10 решённых (также в лог как error).

**Проверка текста** (`moderation.detect.*`): off по умолчанию. Нужен ключ в «Ключи и сервисы» (`openai_moderation`). Тень пишет в `moderation_detections`, enforce: `hold_at` 0,7 уходит на проверку (скрыто), `block_at` 0,97 не публикуется. Таймаут 1,5 с, при сбое пост проходит. Потолок `daily_cap` 20000 запросов в день.

## Ограничения

- Приостановка публикаций работает через общий вход лимитов (`UsageLimitsService.consume`): посты, истории, каналы, вопросы, ответы, комментарии. Статус аккаунта не меняется, пока не сработал последний шаг (блокировка), поэтому отдельной задачи на снятие нет.
- Сетка IP общая у многих (операторы мобильной связи, офис): поэтому общий IP только объединяет жалобщиков в одного, а вес 0 даёт лишь общее устройство с автором.
- 30 настоящих «кукол» с разными устройствами и возрастом могут набрать сумму; для адвокатов с галочкой это закрыто приоритетной проверкой, для остальных есть апелляция и тревога по отменам.
- Приложение не менялось (внешний вид заморожен). Уведомления используют существующий тип `moderation_notice` с новыми значениями `action`; экраны на телефоне для апелляций автомер пока не сделаны, апелляция идёт через API.
