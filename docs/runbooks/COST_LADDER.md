# Лестница расходов LawBid

Для владельца. Цены в долларах в месяц, список цен AWS (us-east-1) и поставщиков, проверено 2026-10-25; «уточнить» значит, что цену ещё надо сверить в кабинете. Каждый пункт имеет положения **Выкл / Вкл / Авто**, где это возможно: «Авто» значит, что система сама включает и выключает по сигналу и не выходит за потолок. Страница в админке: **Расходы**.

## 6. Как переключать

- **Из админки** (настройки приложения и автомасштабы): **Расходы** → строка → положение Выкл / Вкл / Авто → код 2FA. Действие записывается в журнал.
- **Через Terraform** (всё, что живёт в AWS): строка в `infra/envs/prod/terraform.tfvars`, затем «примени Terraform» (plan, `plan-guard.sh`, ваш ответ «да»). Подробности: гид «Terraform plan и apply через наши скрипты».

Как ограничен рост без вашего участия: потолок серверов 50 и 20 копий и правило «Экономика»; размер базы и Redis не выше суммы, которую допускает правило «Экономика» (база до 35 %, Redis до 15 %); дневной тормоз расходов; лимиты SMS, писем, переводов, видео и проверок в деньгах; письма при росте GuardDuty, WAF и CloudFront.

Внимание про репозиторий: GitHub Actions бесплатны, пока репозиторий **публичный**. Если его сделать приватным, появится расход на минуты.
