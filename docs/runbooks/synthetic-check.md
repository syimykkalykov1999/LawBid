# Синтетический пользователь (S11-5)

Скрипт `scripts/ops/synthetic-check.mjs` ходит в прод как человек. Запускается
после каждого Deploy и каждые 5 минут (`synthetic.yml`, GitHub не умеет чаще).

Всегда: `/health/ready` (и версия), `/api/v1/config/bootstrap`, вход с заведомо
неверным номером (должен вернуть аккуратную ошибку 400, не 5xx).
Если заданы секреты `SYNTHETIC_IDENTIFIER` и `SYNTHETIC_PASSWORD` (отдельный
тестовый аккаунт с паролем): вход, запрос под токеном, рукопожатие Socket.IO на
`/realtime`, выход.

Чего ещё нет (честно): создание тестового дела и сообщение «эхо» нужны тестовой
организации, которую не видят настоящие пользователи; это отдельный шаг, когда
такая организация появится. Следующий уровень AWS-нативно: CloudWatch Synthetics
canary (~$1-3 в месяц) с тревогой в `lawbid-prod-alerts`.

Тревога: issue `[ci-alert:synthetic]` + письмо через SNS (если задан `AWS_NOTIFY_ROLE`).
Что делать: открыть последний запуск Synthetic check, прочитать, какой шаг красный;
версия не та = выкладка не закончилась (Deploy / ECS), 5xx = [api-5xx.md](api-5xx.md),
сокет = [REALTIME_LIFECYCLE.md](REALTIME_LIFECYCLE.md).
