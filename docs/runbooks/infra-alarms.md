# Тревоги инфраструктуры: что значат и что делать (аудит S4-4, 2026-10-25)

> **Для владельца:** эти тревоги приходят письмом (тема `lawbid-prod-...`).
> Каждая стоит $0,10 в месяц. Срочного действия в первую минуту почти никогда
> нет: приложение либо чинится само, либо ждёт вашего решения «увеличить».

| Тревога | Что случилось простыми словами | Что делать |
|---|---|---|
| `db-free-storage` | В базе осталось меньше 10 ГБ места | Админка → Здоровье системы → увеличить диск. Если срабатывает после паузы автоувеличения: включите её (db-autoscale.md) |
| `db-free-memory` | У базы почти нет оперативной памяти | Увеличить базу на один размер (админка) |
| `db-cpu` | База загружена > 85 % 15 минут | Обычно сама вырастет (автомасштаб); повторяется ежедневно: поднять потолок размера |
| `db-disk-queue` | Диск базы не успевает | Подождать 15 минут, потом увеличить диск или базу |
| `db-read-latency`, `db-write-latency` | Чтение / запись в базу дольше 50 мс | Посмотреть нагрузку (db-contention.md), при повторе увеличить диск |
| `api-memory`, `worker-memory` | Серверу не хватает памяти > 85 %, дальше его убьёт система | Если письма повторяются: Claude «памяти не хватает» (поднимем размер) |
| `alb-elb-5xx` | Сам балансировщик отвечает 5xx (нет живых серверов) | api-unhealthy.md |
| `acm-expiry-<id>` | HTTPS-сертификат истекает через < 21 день | Проверить запись проверки (CNAME `_xxx.acm-validations.aws`) у регистратора домена; без неё сертификат не продлится и сайт перестанет открываться |
| `nat-port-alloc-<n>` | Выход в интернет исчерпал порты | nat-endpoints.md (второй NAT или эндпоинты) |
| `fargate-vcpu-on-demand`, `fargate-vcpu-spot` | Использовано > 80 % лимита AWS на процессоры серверов | AWS Console → Service Quotas → AWS Fargate → Request increase (бесплатно, 1–3 дня). Нужно >= 100 vCPU при потолке 50 API + 20 worker |

Пороги задаются переменными модуля `infra/modules/monitoring/coverage.tf`
(`db_free_storage_alarm_gb`, `db_free_memory_alarm_mb`,
`fargate_quota_alarm_percent`; 0 выключает квоту Fargate).

## Метрики CloudWatch и расходы (S4-13)

Каждый уникальный набор измерений в наших метриках `LawBid/*` стоит
$0,30 в месяц. Раз в месяц проверьте число метрик:

```sh
aws cloudwatch list-metrics --namespace LawBid/lawbid-prod --query 'length(Metrics)'
```

Больше нескольких сотен — писать Claude «метрики CloudWatch растут». Порог
тревоги NAT снижен со 100 до 20 ГБ в сутки ($0,9 вместо $4,5 в сутки).

## KMS: один ключ на всё (S4-15, сделаем позже)

Сейчас один ключ шифрует S3, секреты, логи, RDS и бэкапы. Разделение на
`data` / `logs` / `secrets` и запрет `kms:ScheduleKeyDeletion` всем, кроме
аварийной роли, требует пере-шифрования секретов; пока владелец один и
тревога на удаление ключа есть (security-baseline), риск принят. Вернуться,
когда появится второй администратор.


## Дополнения S12 (наблюдаемость, 2026-10-25)

Подробности по SLO, аномалиям и дашборду: `slo.md`. Короткие ответы на тревоги с метками ниже.

### search
Поиск в Postgres стал медленным (p95 выше порога 15 минут). Включите отдельный поиск: админка → Настройки → `search.engine` = `shadow`, потом `engine`. Подробно: `docs/architecture/SEARCH_READY.md`.

### storage-growth
Файлы или база выросли за сутки быстрее нормы. Админка → Система → Хранилище → «Кто занимает больше всего» и «Самые большие таблицы»; при необходимости поставьте пользователю лимит.

### r2
Cloudflare R2: хранилище выше бесплатных 10 ГБ или необычно много операций записи. Админка → Система → Хранилище (строка Cloudflare R2). Ничего срочного, цена — $0.015 за ГБ в месяц.

### treasury
Деление денег Stripe на «Прибыль» и «Расходы» и зарплаты: прочитайте текст тревоги, он говорит, что именно сделать в Stripe. Деньги остаются на балансе Stripe.

### economy
Ограничения экономики сами включились или сняты, ночная сверка денег нашла расхождение, база или Redis под нагрузкой. Админка → Система → Экономика. Расхождение сверки: пришлите логи воркера (`ledger_mismatch`) Claude.

### usage
Расход Cloudflare / Bunny приблизился к платной границе. Пороги: админка → Настройки (`usage.*`). Напишите Claude «трафик звонков» или «трафик видео».
