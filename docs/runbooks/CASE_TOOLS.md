# Счета, подписи и комментарии в кейсах — что включить в админке

Всё по умолчанию выключено или нейтрально: пока вы ничего не меняли, приложение
ведёт себя как раньше. Настройки — в админке, раздел Config (ключи `case_tools.*`
и `case_comments.*`). Любая правка — один шаг 2FA и запись в журнал.

## Счета (invoices)

Статусы: draft, sent, viewed, partially paid, paid, overdue, void.

| Что нужно | Ключ в Config | Значение |
|---|---|---|
| Срок оплаты по умолчанию | `case_tools.invoice_default_due_days` | 0 = без срока (напоминаний не будет) |
| За сколько дней напоминать | `case_tools.invoice_reminder_days` | `3,0` |
| Как часто напоминать о просрочке | `case_tools.invoice_overdue_remind_every_days` | 7 (0 = не напоминать) |
| Ссылка на оплату | `case_tools.invoice_pay_link` | true = к счёту создаётся запрос на оплату в приложении (нужны включённые платежи и Stripe у адвоката) |
| Пеня за просрочку | `case_tools.invoice_late_fee_percent` | 0 = выключена. Включайте только если пеня есть в договоре адвоката с клиентом (Retainer Agreement) |

Оплата через ссылку сама обновляет счёт: часть суммы — partially paid, вся — paid.
Бухгалтерской книги (ledger, PR #335) на момент этой работы в main нет, поэтому
проводки по счетам не пишутся; когда книга появится, подключается в
`apps/api/src/modules/case-payments/invoice-reconcile.ts` одной строкой.

## Подписи (e-sign)

| Что нужно | Ключ | Значение |
|---|---|---|
| Срок запроса на подпись | `case_tools.sign_expiry_days` | 0 = не истекает |
| Напоминание тому, кто не подписал | `case_tools.sign_reminder_every_days` | 0 = выключено |
| Максимум напоминаний | `case_tools.sign_max_reminders` | 3 |
| Пауза между ручными повторами | `case_tools.sign_resend_cooldown_minutes` | 60 |

Истёкший запрос получает статус canceled и отметку «истёк»; отправитель может
отправить его заново. Кто и когда открыл документ — пишется в журнал кейса
(первый просмотр каждого) и в сам запрос (последние 50).

## Комментарии к кейсам

`case_comments.edit_window_minutes` — сколько минут автор может править (15;
0 = правка выключена), `case_comments.edit_max_edits` — сколько правок (5).
Каждый прежний текст сохраняется на сервере для юридического аудита; в приложении
пока ничего не меняется (метка «изменено» придёт в ответе API, показать её можно
позже).
