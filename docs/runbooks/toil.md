# Учёт ручной рутины (toil)

## Коротко для владельца
Рутина — это ручная, повторяющаяся работа, которую можно поручить машине и которая растёт вместе с проектом. Google держит её не больше 50 % времени инженера. Здесь записано, какая у нас рутина, сколько примерно она занимает в месяц и что решено: **автоматизировать** или **оставить**. Пересмотр раз в квартал, вместе с `INCIDENT.md`.

Источник: Google SRE Book гл. 5 «Eliminating Toil» (определение: manual, repetitive, automatable, tactical, no enduring value, scales with growth; цель ≤ 50 %), SRE Workbook гл. 6 «Eliminating Toil» (учёт, оценка, «toil budget», приоритет по выигрышу). Пакет Б4 из `docs/dev/STAGE2_SRE_CLOUD_2026-11-25.md`.

## Как вести
- Новая ручная операция, сделанная второй раз, — строка сюда (кто делает, как часто, сколько минут).
- Время — **оценка**, пока нет замера. Замер: число запусков из GitHub Actions / журнала `docs/dev/HELPER_QUEUE_2026-11-03.md` за месяц × минуты на раз.
- Решение «автоматизировать» = issue со ссылкой на эту строку. «Оставить» = написать почему (риск, деньги, правило владельца).
- Раз в квартал: пересчитать, закрыть сделанное, сверить долю рутины (цель ≤ 50 % времени).
