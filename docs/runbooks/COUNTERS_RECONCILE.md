# Счётчики в профилях: разовая починка и ночная сверка

Что было не так: после удаления поста число «Посты» в профиле иногда оставалось старым (если при удалении ролика падала очистка видео, счётчик не уменьшался), а новые публикации прибавлялись к этому старому числу. Ночная сверка чинила только профили, которые «трогали» последние 2 дня, поэтому неверное число жило вечно.

## Починить сейчас (прод)
1. Посмотреть, сколько профилей неверны (ничего не меняет):
   `npm run counters:reconcile --workspace apps/api`
2. Исправить:
   `npm run counters:reconcile --workspace apps/api -- --apply`
Нужна переменная `DATABASE_URL` прода. Можно повторять.

## Дальше само
Ночная работа `counters.reconcile` (04:50) теперь ещё обходит профили по кругу и чинит расхождения. Админка → Настройки: `counters.drift_sweep` (off / on / auto, по умолчанию auto) и `counters.drift_sweep_batch` (5000 профилей каждого вида за ночь).

## Как проверить
Создайте 3 поста, удалите 1: в профиле «Посты» = 2, добавьте фото/пост: 3. Тест: `test/owner-profile-post-counter.e2e-spec.ts`.
