## ✅ Работает (проверено)

- Состояния дела: сравнение версии и статуса, неверный шаг → 409, просьбы сбрасываются при отказе и возобновлении; только другая сторона отвечает; обе стороны получают уведомление и строку в чате.
- Принятие ставки: сначала блокируется дело, потом ставка, serializable и сравнение версии. Два принятия разом, принятие против отзыва или встречного предложения — исход верный. Проигравшие ставки один раз становятся `rejected_auto`, записываются в журнал и получают уведомление.
- Дубли ставок: уникальный ключ (дело, адвокат), рекомендательная блокировка, блокировка фирмы. Не больше 5 раундов, раунды по порядку.
- Пакеты ставок: баланс не уходит в минус, возврат один раз, оплата идемпотентна, книга в той же транзакции.
- Журнал дела: строка дела заблокирована, время монотонное (мс), история и выгрузка с `withDeleted`, лента ограничена 500.
- Сроки: правило FRCP 6(a), выходные, перенос праздников, целые дни (без летнего времени), напоминания один раз.
- Файлы: в presign точный размер и тип, ключи случайные, подтверждение сверяет размер и sha256, а большие файлы проверяет воркер. Копия лежит по ключу, куда ссылка загрузки не пишет. Без антивируса `clean` файл не прикрепляется. Закрытые файлы — по коротким подписанным ссылкам и только участникам дела.
- Юридические документы: публикация и откат в serializable, принимается только текущая версия, ETag на публичных.
- Путь медиа (сжатие на телефоне → прямая загрузка → ключи в базе → CDN) — подтверждён в #1213.
