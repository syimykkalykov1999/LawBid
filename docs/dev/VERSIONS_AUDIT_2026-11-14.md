## How to repeat

Scripts used (local, not in git): npm — for every dependency read `npm view <name> time dist-tags --json`, take the highest `x.y.z` with a date ≤ cutoff and ≤ the `latest` tag; pub — `flutter pub outdated --json` + `https://pub.dev/api/packages/<name>` (`published`); actions — `gh api repos/<owner>/<repo>/releases` sorted by version (`sort -V`, not by date: maintenance releases of old majors are published later), then `gh api repos/<repo>/commits/<tag>` for the SHA; images — Docker Hub `v2/repositories/library/<image>/tags/<tag>` (digest + architectures) and the upstream release date of the software, not the image rebuild date.
