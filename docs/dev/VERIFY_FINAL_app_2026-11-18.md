## ❌ Было сломано → исправлено

- **FA1. Приватность без сети: одно нажатие стирало весь экран.** После #1245 (PS4) отказ сервера перечитывает настройки; если и это чтение падает (нет сети), провайдер перезапускался, падал ещё раз, и вместо строк «Кто видит…» вставал полноэкранный «Ошибка / Повторить». Теперь при неудачном перечитывании назад откатывается только нажатая строка (или «Не продавать»), остальное на месте, снизу та же плашка с причиной. `privacy_providers.dart`; тест `privacy_notifier_test.dart` «offline…».
- **FA2. Возврат клиенту, на который Stripe не ответил: «Что-то пошло не так».** #1251 добавил ответ `503 REFUND_PROVIDER_FAILED` («нажмите ещё раз — уйдёт тот же возврат»), в приложении у кода не было текста. Теперь у кода свой текст на всех 86 языках (`error.api.REFUND_PROVIDER_FAILED`, `scripts/i18n-add.mjs`), ассеты строк сайта пересобраны. Тест `api_error_text_test.dart`.
- **FA3. Адвокат с двумя делами одного клиента не мог оценить клиента во втором деле, и отказ возвращался при каждом запуске.** #1251 сделал второй отзыв той же пары `409 REVIEW_ALREADY_EXISTS` («редактируйте тот, что есть»). Но на деле у адвоката нет id клиента, `GET /cases/:id/client-review` второго дела отвечал «нет отзыва» (пустая форма), а очередь отзывов (`review_outbox`) показывала «Вы уже оставили отзыв по этому кейсу» с «Повторить», которое не может помочь, и так при каждом старте. Теперь сервер делает то, что задумано в #1251: в деле, где у этой пары нет своего отзыва, `GET` показывает живой отзыв адвоката об этом клиенте (только нанятому адвокату этого дела — чужой ничего не узнаёт), а `PUT` правит его (как `PUT /clients/:id/reviews/mine`), второй строки по-прежнему нет. `client-reviews.service.ts`; e2e `owner-client-profile.e2e-spec.ts` «a second case…».
- **FA4. Картинка во время «Изменить» уходила с текстом редактируемого сообщения как подписью.** GIF с клавиатуры и вставка (#1253), перетаскивание и скрепка во время правки старого сообщения брали поле ввода (а там текст правки) как подпись: в личном чате он вставал подписью в просмотр, в группе файл сразу уходил с этим текстом и поле очищалось. Теперь во время правки файлы уходят без подписи, правка остаётся как была (личный чат и группы, телефон и сайт). `conversation_screen.dart`, `group_conversation_screen.dart`; тесты `chat_keyboard_media_test.dart`, `group_draft_test.dart`.
- **FA5. Сайт: стрелки на вкладке «Посты» листали спрятанные рилсы.** Лента держит страницу «Рилсы» живой рядом с «Постами» (тикеры выключены). `ReelWebPager` (#1254) брал фокус один раз (`autofocus`) и не отдавал: ↓ на «Постах» ставила шаг рилса, который доезжал при возвращении — рилсы прыгали. Теперь фокус берётся, когда страница рилсов на экране, и отпускается, когда она уходит. `reel_web_stepper.dart`; тест `reel_web_stepper_test.dart` «the keys page the reels only while their page is shown».

## ✅ Проверено, исправлять нечего (почему)

- **SYNC_TOO_OLD 409 у уведомлений (#1250).** Список колокольчика — `SyncedListNotifier`, он на этот код забывает метку и перечитывает первую страницу. Другие «дельты» уведомлений (`task_reminders`) читают задачи, не уведомления.
- **AUTH_OTP_EXPIRED 401 на «продолжить на этом телефоне» (#1245, AU3).** Тот же код уже приходил при истечении 5 минут; `AuthInterceptor` трогает только `TOKEN_EXPIRED`, `AUTH_SIGNED_IN_ELSEWHERE`, `AUTH_SESSION_REVOKED`, текст «код истёк, войдите снова» есть.
- **`registered: true, hasPassword: false` в `/auth/phone/status` (AU1).** `phone_screen.dart` в том же PR открывает «Забыл пароль».
- **ACCOUNT_SUSPENDED / ACCOUNT_DELETED на «Забыл пароль» (AU2) и на входе во время удаления (#1258).** Тексты есть; вход в срок удаления снова отменяет удаление по умолчанию — это совпадает с текстом приложения «отменить удаление, просто войдя снова».
- **404 на перевод скрытого «О себе» (#1252).** Профиль присылает скрытое «О себе» как null, кнопки «Перевести» тогда нет; 404 возможен только в гонке и показывается обычной плашкой (`showErrorOrPlans`).
- **USER_BLOCKED у подписки и новые проверки блокировок (#1245).** Подписка откатывает кнопку и показывает текст кода.
- **FIRM_FULL / FIRM_ALREADY_MEMBER / FIRM_OWNER_MUST_TRANSFER / ASSISTANT_SEATS_IN_USE / PAYMENT_INVALID_STATE / REVIEW_APPEAL_EXISTS / REVIEW_NOT_EDITABLE.** У всех кодов есть тексты (`api_error_text.dart`), экраны показывают их плашкой.
- **`queued` у «Пересчитать всех» (доверие, #1259).** Только админка, приложение этот адрес не вызывает.
- **Отказ войти в комнату чата для бывшего члена команды бида (#1259).** Приложение и раньше получало `{ok:false}` для чужого чата.
- **Токен в пачке событий (#1255, AN2).** Адрес публичный, просроченный токен сервер молча считает гостем (событие не теряется, ответ «нет» на телефоне всё равно не пускает события).
- **Кэш списка поддержки (#1255, SU3).** `mustAskAgain` спрашивает сервер (`If-None-Match`) после своего изменения и при «потянуть вниз».
- **`#1253` прочее.** Вставка на сайте не перехватывает текст вместе с картинкой, слушает только верхний экран (`ModalRoute.isCurrentOf`) и снимается в `dispose`; GIF с клавиатуры идёт из памяти (`readAsBytes`, без пути к файлу); GIF разрешён ровно там, где скрепка (контакты открыты, у помощника право «файлы»); клавиатура за пальцем — только iPhone, Android и сайт как были.
- **`#1254` прочее.** Колёсико ловится только над рилсами, во время доезда страница не берёт пиксели колеса, на телефонах пейджер прежний.
- **Строки сайта.** `dart run tool/gen_static_strings.dart` после правки — ассеты совпадают с кодом (`static_strings_asset_test`).
