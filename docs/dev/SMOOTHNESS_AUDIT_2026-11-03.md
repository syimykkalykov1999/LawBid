## 6. Админка (пункты 7–8), замеры 03.11.2026

Метод: `next build` (Next 16.4.3, Turbopack; он больше не печатает размеры маршрутов) + скрипт: для каждого маршрута берутся скрипты из `build-manifest.json` (rootMain, polyfills) и `entryJSFiles` из `page_client-reference-manifest.js` (layout-цепочка + страница), размер считается gzip-6. Это «JS первой загрузки» маршрута; лениво подгружаемое (Sentry 163 КБ, движок motion) в него не входит, как и в реальной загрузке. 111 маршрутов.

| Маршрут | До, КБ gzip | После, КБ gzip |
|---|---|---|
| /desk/[role] (самый тяжёлый) | 412,7 | 349,2 (−63,5) |
| /integrations | 390,3 | 377,6 (−12,7) |
| /verification/trust | 385,8 | 369,3 (−16,5) |
| медиана по 111 маршрутам | 337,7 | 333,7 |

Что сделано: стол `/desk/[role]` тянул в бандл 8 полных страниц (платежи, выплаты, казначейство, поддержка, модерация…) ради одной открытой вкладки — теперь каждая страница грузится при открытии своей вкладки (`next/dynamic`, скелет `Skeleton` как и раньше у страницы). В `/integrations` ниже первого экрана «Реестры штатов» и диалог «Новый сервис» стали динамическими. В `/verification/trust` три вкладки (адвокаты, клиенты, решения персонала). `@simplewebauthn/browser` грузится только при запросе ключа (вход / подтверждение), а не вместе с каждой страницей, где есть диалог подтверждения.

`experimental.optimizePackageImports: ['@phosphor-icons/react', 'motion/react']` добавлен по документации Next.js. Честно: на размер боевой сборки Turbopack он не повлиял (цифры до/после включения одинаковы до байта) — Turbopack уже отбрасывает неиспользуемые иконки; эффект ожидается в `next dev` и при сборке webpack. Отдельно в `dev` не измерялся.

Что осталось общим для всех маршрутов (~330 КБ): React/Next (~165 КБ), motion-ядро (~41 КБ), чанк с иконками боковой панели (~45 КБ), TanStack Query, tailwind-merge. Это оболочка админки; резать её без изменения вида нельзя.

Пункт 8 (`use client`): все крупные страницы — клиентские целиком (хуки, TanStack Query, состояние вкладок), серверной презентационной части, которую можно вынести без изменения поведения, в них нет; серверными уже являются `today`, `login`, `guides`, `staff`, `legal`. Не трогали, чтобы не рисковать поведением.

Не измерено: Lighthouse / CPU ×4. Страницы админки закрыты сессией и API, без стенда с API страница уходит на `/login`; инструмент Lighthouse в DevTools-MCP не считает performance. Остаётся прогнать на стенде с API.
