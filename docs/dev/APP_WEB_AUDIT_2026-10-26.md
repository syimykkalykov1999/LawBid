## Нужно решение владельца (меняет вид или продукт, не трогали)

1. A4 Карточка оплат молча пропадает при ошибке сети — показать строку «Повторить»?
2. A6, C5 Списки вопросов, шаблонов и сетка постов в профиле после ошибки подгрузки останавливаются навсегда; в профиле кнопка «Загрузка…» выглядит как спиннер. Нужна строка «Повторить» и автоподгрузка.
3. A9 Лист задачи — вечный скелетон при ошибке.
4. A16 Вкладки дела «Файлы / Обновления / Активность / Время»: ошибка без «Повторить»; длинные списки строятся целиком (медленно на сотнях записей).
5. A18 Калькулятор сроков: можно дважды добавить один срок.
6. B3 Чтение старых сообщений: новый входящий сдвигает текст под пальцем.
7. B8 Чат без сети: можно читать, но нет поля ввода.
8. B9 Вложения в группе нельзя повторить после ошибки.
9. B23 Повтор неотправленного сообщения мигает.
10. C16 Рилсы держат видео-декодеры, пока вкладка скрыта (риск на слабых Android).
11. C20 Удалённый пост на секунду виден из офлайн-копии после перезапуска.
12. D1 Удаление аккаунта работает только с номером +1 (email-аккаунт и другие страны не могут удалить) — нужен шаг «код отправлен на …». Важно для закона о данных.
13. D5 Заблокированный аккаунт при входе по коду видит «Ошибка сети» вместо «Аккаунт заблокирован».
14. D8 Экран «аккаунт удалён, 30 дней на восстановление» не успевает показаться.
15. D14, W3 На сайте обновление страницы на вложенном экране (настройки, чат, дело, юр. тексты) открывает ленту.
16. W4, W5, W6, W7 Мелочи веба: время налезает на текст, двойная дата, Esc, текст про микрофон.
17. Редкие экраны на сайте (DeferredScreen) показывают крутилку, если их файл грузится дольше 0,4 с — оставить или убрать.
