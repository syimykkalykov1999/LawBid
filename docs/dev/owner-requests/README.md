# Все сообщения владельца — дословно

Здесь каждая просьба, правка и замечание владельца из переписок с ИИ, слово в слово, по дням (время UTC). Это нужно, чтобы любой следующий ИИ видел, **как именно** владелец хотел каждое исправление, а не пересказ.

## Как пользоваться (для ИИ)
1. Сначала прочитай [`../HANDOFF_2026-10-29.md`](../HANDOFF_2026-10-29.md) — там свежее состояние и таблица находок со статусом.
2. Потом читай файлы по датам, начиная с последних (`2026-10-29.md`, `2026-10-28.md` …). Когда владелец говорит «видишь недоделанное — доделай», ищи здесь его точные слова.
3. Сделано или нет — проверяй по коду и истории git (`git log --all --grep`, открытые PR), а не по памяти. Не сделанное — доделай так, как он сформулировал, по правилам [`../../../AGENTS.md`](../../../AGENTS.md).
4. Ответы ИИ здесь не сохранены — только слова владельца. Если в сообщении он цитирует ответ ИИ, это его вставка.

## Что важно знать
- Личные данные заменены: [email], [ip], [phone], [token], [aws-account]. Пароли и ключи не публикуются (репозиторий публичный).
- «[скриншот]» — к сообщению был приложен снимок экрана телефона; сами снимки не публикуются (на них личные данные). Если нужен смысл — он обычно в тексте рядом.
- «(из сводки, время примерное)» — сообщение восстановлено из сжатой копии переписки.
- `00_SUMMARIES.md` — пересказы всех сообщений из сжатий переписок (по-английски).
- **Пробелы:** переписки со 2 по 12, с 14 по 17 и с 19 по 20 октября на Mac не сохранились; от них есть только то, что попало в сводки. Работа тех дней видна в истории git.
