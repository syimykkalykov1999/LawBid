Every worker brief must say to research with WebSearch/WebFetch (mode extended for niche items) and to prefer sources from 2025-2026: current docs, recent engineering blogs, current prices. Note the date of each source in the report. If web search is unavailable, the worker must say so, and the coordinator re-runs the research.
**Why:** the owner (2026-10-24) said to study fresh things, not old; the benchmark worker wrote from memory without searching.
**How to apply:** add the line "Research with live web search, prefer 2025-2026 sources, cite dates" to every research or build brief. Related: [[research-first-workflow]]
