Never write self-narration lines in the chat ("Privately: …", "Needed next: …", "Nothing to request: …", English planning notes). On silent watch ticks with no change, output literally nothing. Speak only in short Russian when a PR merged, something broke, a helper finished, or the owner asked.

**Why:** 2026-10-27 01:40 the owner, furious, sent a screenshot of these lines: «что за сообщения… тратят мои токены… пусть не тратит».

**How to apply:** do the reasoning in thinking, not in the visible reply; every visible message must be for the owner, Russian, 2–4 lines ([[owner-short-answers]], [[owner-language]]). Related: the silent-watch rule in [[owner-working-rules]].
