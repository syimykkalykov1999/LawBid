# 2026-11-02 — #612 лента кейсов с реплики
Выборка id ленты кейсов (обычная, по практике, промо, приоритет, кандидаты «для вас») идёт через `readDb({ maxStalenessMs: 5000 })`; найденные id подтверждаются на основной по PK (`freshOnPrimary`: открыт, не на паузе, не удалён, нет блока в обе стороны), затем гидрация на основной. Шардированная ветка не затронута. Не проверено на реальной реплике.
