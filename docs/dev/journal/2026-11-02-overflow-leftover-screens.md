# 2026-11-02 — тест на наезжающий текст для 16 непокрытых экранов

PR: (номер — в описании PR), ветка `claude/project-thread-4orbk3`. SHA слияния: допишется после слияния.

Что сделано: статический проход по `apps/mobile/lib` (Row с Text без Flexible/Expanded) и поиск экранов, которых не касается ни один тест. Таких экранов 52. Для 16 из них, где экран собирается без сложных фейков (пакеты ставок, приглашения, о приложении, удаление аккаунта, блокировки, доверие, поддержка, демо-код, мои продвижения, фирма, контакты, значок клиента, выплаты, лист ожидания страны, рефералы), добавлен `test/overflow/leftover_screens_overflow_test.dart`. Каждый экран на 360 dp, самые длинные переводы всех ключей, RTL, ne, ar, ru, масштаб 1 и 1.1: 160 прогонов, переполнений нет, правок кода не потребовалось.

Не проверено: на телефонах; экраны с данными (тест видит состояние по умолчанию); остальные 36 экранов без теста (камера, просмотр историй, чат-видео и др.).
Шрифты (квадратики): в приложении только Inter/Source Serif (латиница, кириллица, греческий), остальные письменности идут через системный fallback; на вебе — загрузка Noto с fonts.gstatic.com (CSP это разрешает). Свои Noto-подмножества не встроены — передано треду переводов.

## Дополнение: шрифт 1.3, de, mr
Оболочка приложения допускает системный шрифт до 1.3 (`DeviceTextScale.shellMax`), а 19 тестов проверяли только 1.1. Все overflow-тесты теперь идут на 1.0/1.1/1.3 и с языками de и mr (6118 тестов зелёные). Найдено и починено при 1.3: шапка экрана звонка (фиксированная высота 52 → минимум 52, 2 px) и подпись типа группы в шапке «Инфо группы» (22 px, теперь Flexible + ellipsis). Тест кнопок «Сегодня» при 1.3 допускает перенос на 2 строки (без переполнения).
Не проверено на телефоне.
