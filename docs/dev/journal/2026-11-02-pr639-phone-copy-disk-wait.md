# 2026-11-02 (PR #639): копия телефона не опаздывает за лимитом списка

**Что искали и где.** Чтение копии с диска ограничено `diskReadWait` (1,5 с) в `HttpCacheInterceptor._readDisk`; список ждёт копию `PagedNotifier.savedCopyTimeout` = 1 с. Холодный старт и офлайн отдельно не проверялись тестами (есть только `readFromPhoneOnly` на живом диске). Второго механизма нет.

**Что сделано.** Для чтения «только с телефона» диск ждётся `phoneOnlyDiskWait` = 0,8 с (меньше 1 с списка): медленный диск = быстрый промах, дальше обычная сеть; обычные запросы по-прежнему 1,5 с. Тесты: медленный диск (промах быстрее 250 мс, запросов нет, обычный путь копию берёт), холодный старт без сети (копия есть, живое чтение отдаёт устаревшую копию, не пустоту).

**Осталось / не проверено.** Реальный телефон: холодный старт, самолёт, 304 на медленной сети (HANDOFF «Ждёт устройства»).

Не закрыто (осознанно): список «Завершённые ставки» читает несколько страниц подряд, лимит 1 с на всё чтение; при нескольких медленных чтениях копия не успеет — тогда список ждёт сеть как раньше.
