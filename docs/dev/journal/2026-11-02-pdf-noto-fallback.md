# 2026-11-02 — шрифты по письменности в серверных PDF

Ветка claude/pdf-noto-fallback (от #583 с Noto). `apps/api/src/common/pdf-fonts/pdf-fonts.ts`: строка делится на куски по письменности, каждый рисуется Inter или Noto (арабский/иврит — с разворотом порядка, минимальный bidi; индийские, тайский, кхмерский, лаосский, бирманский, грузинский, армянский, эфиопский). Все 5 генераторов PDF (pdf-common, история дел, юр. выгрузка, квитанция, пакет спора) идут через `applyPdfFonts`. CJK (SC/JP/KR) качается с CDN при старте API и воркера (sha256, диск-кэш), только когда в manifest.json `uploaded: true`; пока их нет, китайские/японские/корейские знаки в PDF остаются рамками. Тест `pdf-fonts.spec.ts` проверяет все 85 языков из xlsx: у каждого знака (кроме CJK и значков-символов) есть глиф в выбранном шрифте. На устройстве/в Acrobat не проверялось, только pdftoppm. SHA: допишу после слияния.
