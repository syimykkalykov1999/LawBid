# 2026-11-03 — перевод ячеек, равных английскому (ветка claude/i18n-fill-all-languages)

Причина: владелец увидел английский на киргизском iPhone (Данные и память, Конфиденциальность, Платежи...). В сиде ky для этих ключей перевод уже был, значит английский брался не из сида.

Найдено:
- Сид-ячейки, равные английскому (без брендов/цифр/аббревиатур): 2272 в 84 языках; 1909 ячеек не было вовсе у 23 ключей, которые есть только в Dart ru/en (на любом не-ru/en языке показывался английский).
- Вероятная причина английского на телефоне: deploy-импорт --missing-only не трогает ячейку, уже лежащую в БД, даже если там старая английская копия. Исправлено в I18nImportService: ячейка не-en языка, равная английскому тексту в БД и не правленная в админке, заменяется текстом из сида. НЕ проверено на проде (БД недоступна).
- Виджеты читают тексты по ключам (t.t), захардкоженного английского в features/ нет.

Сделано: 364 ячейки переведены, 1909 новых (23 ключа x 83 языка), остальные «слово совпадает с английским» (1908+19) внесены в scripts/i18n-same-as-english.allow.json. Новая проверка в scripts/i18n-audit.mjs --ci (ячейка = английскому вне allowlist, ключи Dart без строки в сиде) + node --test scripts/lib/same-as-english.test.mjs.
