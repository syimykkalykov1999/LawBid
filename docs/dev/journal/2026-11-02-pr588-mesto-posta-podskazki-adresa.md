# 2026-11-02, PR #588: место у поста и рилса с подсказками адреса

Дата: 2026-11-02. PR: #588 (ветка claude/project-thread-unx9ja-post-place). SHA слияния: допишет диспетчер.

## Что сделано
- В форме нового поста и рилса поле «Место» на готовом `AddressField` (подсказки через серверный `GET /addresses/suggest`, новых провайдеров нет). Стоит после списка @упоминаний; автозаполнение ОС выключено (`autofillHints` пуст), чтобы телефон не подставил домашний адрес в публичный пост.
- Значение обрезается до 120 символов при публикации (подсказка ставится из кода и обходит `maxLength` поля, сервер отвечает 400 на длиннее).
- Запрос ассистента без права publish теперь несёт `location: {name}`; при одобрении адвокатом место попадает в пост.
- Подпись поля: свой ключ `post.create.placeHint` (переводы на 85 языков из `tasks.steps.placeHint`: «Адрес / место»).

## Что искал
`AddressField` и `/addresses/suggest` уже есть; аудит показал, что единственное поле адреса без подсказок и без отправки — форма поста.

`create_post_fields_test` (поле под подписью, без автозаполнения, нет при правке, обрезка до 120, пусто = без места), `new_screens_overflow_test` (длинное место). Не покрыто тестом: ветка запроса ассистента и `ReelPublishRequest.place` (нужны фейки команды и видео); состояние: проверяет CI.
