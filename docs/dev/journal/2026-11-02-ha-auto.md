# 02.11 Вторая копия базы и запасной Redis: включаются и выключаются сами

Решение владельца. Сервис `ha-auto` в API (`ha.mode` off/on/auto, `ha.provision_online_users` 200, `ha.release_days` 7): добавляет Multi-AZ базы и запасной узел Redis после 3 ч онлайна ≥ порога, убирает после 7 суток < порога/2 (только при данных за ≥ 90 % часов, обратный шаг не раньше чем через 24 ч). Terraform: `database_multi_az=false`, `redis_replicas=0`, `ignore_changes` по узлам Redis, автомасштаб Redis создаётся и без запасного узла, права `elasticache:Increase/DecreaseReplicaCount`. Сейчас обе копии включены, уберутся сами не раньше чем через 7 суток после выкладки (нужны данные за неделю). Риск: при падении зоны, пока копий нет, простой (runbook). На нашей базе не проверено, что AWS переключает без остановки.
