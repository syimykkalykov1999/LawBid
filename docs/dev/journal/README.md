# Журнал шагов

Один влитый шаг = один файл `YYYY-MM-DD-prNNN-кратко.md` в этой папке: дата, PR, SHA слияния, что сделано, состояние. Файл создаётся в том же PR, что и работа (SHA можно дописать после слияния отдельной строкой «SHA: …»). Общий файл PROJECT_MAP.md для журнала не правим: из-за него параллельные PR конфликтовали.
