# 2026-11-02 · Лист ожидания стран: почта необязательна (бэкенд)

Решение владельца: достаточно выбрать страну, ни писем, ни СМС. Бэкенд: `country_waitlist.email` теперь может быть пустым (миграция `20261114100000`, только каталог, без перезаписи таблицы; ключ `country_code+email` остаётся, пустые адреса в нём различны); DTO `email` необязательный; без адреса каждый посетитель (IPv4 или IPv6 /64) даёт один голос в сутки на страну и не больше 30 в сутки всего, лишнее принимается молча и не записывается (при недоступном Redis голос засчитывается); рассылка при запуске страны берёт только строки с адресом (`email: { not: null }`), строки без адреса остаются как счётчик спроса. Общий помощник `common/net/ip-bucket.ts` (взят из приёма крэшей).

Состояние: PR #632, готов к слиянию после зелёного CI.
