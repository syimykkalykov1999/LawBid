# 2026-11-02 · PR #641 · повторное сканирование зависимостей и гейт для админки

После слияния #567 и #608 пересканировали npm в облаке: у API в продакшен-зависимостях critical нет, high только Prisma-CLI (в списке исключений до 2027-01-31, лечится Prisma 7), moderate висят на мажорных обновлениях; `npm audit fix` без `--force` ничего безопасного не меняет. Результаты в `docs/security/SECURITY_AUDIT_2026-11-02.md`, раздел «Повторное сканирование».
