# 2026-11-02 — роль lawbid_partition с наименьшими правами

- Миграция `20261112110000_partition_role_least_privilege`: роль владеет только тремя партиционируемыми таблицами и ссылающимися на них, без доступа к audit_log/case_journal/user_consents/users; `lawbid_migrator` — участник роли.
- Тест `apps/api/src/partitioning/partition-privilege.int.spec.ts` (нужны PARTITION_REAL_URL / PARTITION_REAL_SEED, свежая БД с миграциями): 4 теста на локальном PG16.
- `partition_role_enabled` остаётся `false` по умолчанию (пустой секрет ломает запуск задачи ECS).
- Таблицы принадлежат NOLOGIN-роли `lawbid_partition_tables`; `lawbid_partition` (логин воркера, сессии идут от неё через `ALTER ROLE ... SET role`) и `lawbid_migrator` — обе её участники. Причина: прямая связь «мигратор участник lawbid_partition» делала невозможным повтор слитой миграции `20261112100000` на второй базе того же кластера (GRANT migrator TO partition → цикл; упал e2e на двух базах). Слитую миграцию править нельзя, поэтому цикла нет. Проверено на чистом PG16: 100000 → 110000 на базе 1, 100000 → 110000 на базе 2 и повтор 110000, без ошибок, итог — таблицы у `lawbid_partition_tables`, у логина `role=lawbid_partition_tables`.
