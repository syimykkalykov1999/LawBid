# 2026-11-03 web desktop PR 5: окна вместо шторок + остальные страницы настроек справа
План DESKTOP_WEB_PLAN_2026-10-28 §5.5 / §6.7. Только desktop-окна (>=1024, isDesktopWindow); телефон и планшет без изменений.
Что искали: механика окна уже была (`showAppBottomSheet` -> `DesktopSheetDialog`, PR 1). Все 150+ вызовов идут через неё. Обходили хелпер 4 места: comments_sheet, post_text_sheet, recommended_sheet (свой showModalBottomSheet) и выбор участников группового звонка (group_call_ui). Других `showModalBottomSheet`, `showCupertinoModalPopup`, `showMenu`, `Scaffold.showBottomSheet` в lib нет.
Что сделано:
- `DesktopSheetDialog`: ширина до 480 (было 560), высота до 80% (было 85%); новая `showDesktopSheetDialog`; `showAppBottomSheet` получил `useSafeArea` (по умолчанию как было).
- comments / post text / recommended переведены на `showAppBottomSheet` (`closeByHandleOnly: true`, чтобы телефон остался точь-в-точь: те же рамка, цвет, радиус, ContentColumnFrame, свой DraggableScrollableSheet). Выбор участников звонка: на desktop окно, на телефоне прежний лист.
- Настройки: реестр секций вынесен из features/profile в `core/navigation/hosted_settings_sections.dart` (fan-out profile не растёт, cross-feature импортов нет). К 8 секциям добавлены 14: payments (с ?tab=), subscription, support, saved, archive, case-history, referral (?code=), partner, bid-packs, stars, verify-account, firm, stats, promotions. Их маршруты обёрнуты в `SettingsSectionPage`; `kSettingsSectionPaths` расширен; query хранится в адресе и ключе панели.
- Тесты: desktop_sheets_test (3 листа: окно на 1440, Esc, клик по фону, телефон 390 — лист, Tab не уходит под окно, низкое окно), desktop_profile_settings_test (5 новых страниц в панели на 1440 и обычной страницей на 390, ?tab=, реестр == kSettingsSectionPaths).
Не сделано / ограничения: подстраницы внутри разделов (support/new, support/:id, case-history/:id, stars/gifts, delete-account, set/change password, contacts, trust, team, payout, consultations) по-прежнему открываются страницей поверх всего окна (как и у первых 8). DraggableScrollableSheet внутри окна занимает долю высоты окна (55%), а не «по содержимому». flutter build web и проверка глазами не делались (RAM Мака). RTL тестом не покрыт (Directionality наследуется от приложения, в коде направленных отступов не добавлено).
