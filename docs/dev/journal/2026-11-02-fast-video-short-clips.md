# Быстрое видео: короткие клипы играют MP4

02.11 PR (ветка claude/project-thread-19x69r): клипы до 30 с с MP4-запасным файлом на телефонах играют MP4 (HLS требует три запроса до первого кадра); при ошибке плеер один раз пробует HLS.
