# R-366: у кейса нет «поделиться»

- Дата: 03.11.2026. Ветка: claude/r366-no-case-share. PR: см. описание. SHA слияния: допишет диспетчер.
- Решение владельца: «убери просто кнопку поделиться кейсами для всех … кейс это личное и никак нельзя делиться».
- Приложение: из `_CaseCardRow` (карточка кейса, одна на все роли и все экраны списков) убраны иконка самолётика и счётчик; остальные иконки и отступы те же. Метод `recordCaseShare` (нигде не вызывался) удалён.
- Сервер: `POST /cases/:id/share` теперь всегда 403 (`FORBIDDEN`), ничего не пишет и не считает. Маршрут оставлен, чтобы старые сборки получили 403, а не 404. Пересылка в чат (`forward`) кейсы не принимает: только сообщения, посты каналов, группы.
- Тесты: виджет-тест карточки (нет иконок share), спека `case-comments.share.spec.ts`.
- Не проверено: спека API локально не запускалась (в локальном node_modules нет @nestjs/config), на устройстве не смотрели.
