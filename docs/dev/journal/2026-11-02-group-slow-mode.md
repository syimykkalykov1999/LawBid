# Медленный режим в группах

Сервер: колонка chat_groups.slow_mode_s (миграция 20261110110000, nullable, expand-only), PATCH /groups/:id принимает slowModeS, отправка берёт слот в Redis `SET NX EX` (один быстрый вызов, без записи в БД; при недоступном Redis слот не блокирует). Админ и владелец паузой не ограничены. Отказ: 429 RATE_LIMITED, details.kind=group_slow_mode, retryAfterS.
