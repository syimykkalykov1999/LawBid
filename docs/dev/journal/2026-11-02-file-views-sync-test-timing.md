# 2026-11-02 — тест «просмотры файла» не зависит от скорости машины

В CI на #609 упал `file_views_sync_test.dart` («a file:viewed event for this file is one ?since= request»): тест ждал событие `eventDelay` + фиксированные 100 мс, а чтение копии на телефоне (база) на загруженной машине занимает дольше. К проверке запрос ещё не ушёл (`calls` пуст), затем контейнер закрывался посреди работы, отсюда «Cannot use the Ref … after disposed» в логе (это пойманная и напечатанная ошибка `catchUp`, код приложения верен: `ref.mounted` проверяется).
Правка только в тесте: после `eventDelay` ждём появления самого запроса (до 5 с, шаг 50 мс). Код приложения не менялся. Локально 6 прогонов подряд зелёные до правки и после, ошибку на Linux воспроизвести не удалось (зависит от загрузки).
