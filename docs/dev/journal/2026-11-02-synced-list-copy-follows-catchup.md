# 2026-11-02: сохранённая копия списка групп следует за «догнали до»

**Что нашёл (аудит мобилки, первый экран).** `SyncedListNotifier` хранит «догнали до» на диске, а копию первой страницы групп писал только при полном чтении первой страницы. После догонки (`?updatedSince`) время уходило вперёд, копия оставалась старой. При холодном старте: старая копия + запрос «что изменилось с нового времени» → группа, изменившаяся между ними, оставалась старой на экране.

**Что сделано.** `SyncedListNotifier.didMerge(items)` — после слияния догонки, если дельта не пустая. `GroupsNotifier` перезаписывает копию (до 50 строк, не архив). Если на экране нет строк (загрузка/ошибка), «догнали до» не сдвигается.

**Тест.** `group_sync_test.dart`: после reconnect-догонки копия содержит новые/изменённые группы и не содержит удалённых.

**Не решено.** Копия и «догнали до» лежат в двух разных базах, записи не ждутся: строгого порядка нет (убийство приложения между ними стоит одной лишней дельты). Копия читается без курсора следующей страницы (так было и раньше): у пользователя с более чем одной страницей групп дальше копии список подгружается после pull-to-refresh. На устройстве не проверялось.
