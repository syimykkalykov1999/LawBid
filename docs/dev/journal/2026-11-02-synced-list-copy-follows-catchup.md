# 2026-11-02: сохранённая копия списка следует за «догнали до»

**Что нашёл (аудит мобилки, первый экран).** `SyncedListNotifier` хранит «догнали до» (время) на диске, а копию первой страницы (список групп) писал только при полном чтении первой страницы. После догонки (`?updatedSince`) время уходило вперёд, копия оставалась старой. При холодном старте: старая копия + запрос «что изменилось с нового времени» → группа, изменившаяся между ними, оставалась старой на экране до следующего изменения.

**Что сделано.** `SyncedListNotifier.didMerge(items)` вызывается после слияния догонки, до сдвига «догнали до». `GroupsNotifier` перезаписывает копию (до 50 строк, не архив).

**Тест.** `group_sync_test.dart`: после reconnect-догонки копия содержит новые/изменённые группы и не содержит удалённых.

**Не проверено на устройстве.** Только юнит-тесты.
