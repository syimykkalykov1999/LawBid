# 2026-11-02, PR #607: «Данные и память» по чатам

PR: #607. SHA: слияние PR #607 в main.

## Что сделано
- Таблица `chat_media_files` (кэш-БД v3): адрес картинки → чат; пишется при сохранении сообщений и для картинки превью ссылки (только когда превью показано, то есть переключатель приватности включён).
- Экран «Медиа чатов»: размер по чатам, «Очистить» с подтверждением; чаты без названия в строке «Прочее».
- По ревью: строка индекса не удаляется, пока файл ещё не скачан (забывается через 30 дней); очистка чата оставляет строки, повторная загрузка снова считается за чатом; очистка истории сообщений чистит индекс; запись индекса не ломает запись истории; удаление по 500 ключей.

## Что искал
Связи «файл кэша → чат» в коде не было (кэш ключуется адресом файла), использован существующий `AppImageCaches.chatMedia` для размеров и удаления.

## Не охвачено
Чаты без записи в локальную историю идут в «Прочее». На устройстве не проверялось.
