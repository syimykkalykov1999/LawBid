# Масштаб → «Облако: включить и выключить по кнопке»: работает ли «Вкл» и «Выкл» у каждой строки (проверка по коду, 15.11)

Только чтение кода, прод не трогал. Путь одной кнопки:
1. Админка → запрос.
2. GitHub `infra-apply.yml`: запись переключателя → план → лист плана в админке → код 2FA владельца → применение ролью `lawbid-prod-github-deploy`.
3. Запись файла на main (с 14.11 — `--autostash`) → отчёт в API (с #1097 — повторы при 5xx).

Проверено для каждой строки:
- ключ переключателя есть в белом списке и в переменных прода (тест `infra-switches.spec`: «every key is a real prod variable» — зелёный для всех 34);
- охрана плана `scripts/infra/plan-summary.mjs` (FORBIDDEN_DESTROY — защита данных; план, который удаляет данные, отклоняется до 2FA);
- права роли применения `infra/bootstrap/infra-apply.tf` (включая запреты `NeverLoseData`, `KeepSecrets`).

NEVER_AUTO_DESTROY и OWNER_CONFIRM_OFF касаются только «Авто», ручную кнопку не ограничивают.

**Семь строк, где «Выкл» не может пройти по замыслу.** Выключение удаляет хранилище с данными (корзину S3, секрет, группу Redis), а охрана «никогда не терять данные» это отклоняет: synthetics, athena, s3, redis_cache, partition_role, aws_config, audit_logs.

Предложение (отдельной задачей, с применением владельца): «Выкл» выключает только платную часть, а корзина или секрет остаётся (они почти ничего не стоят). Для этого в каждом модуле хранилище выносится из-под переключателя с блоком `moved`. Охрану данных не ослабляем.

## Строки «Не получилось», которые не сходили никогда — исправлено в этом PR
- Причина: проваленный запрос никогда не попадает в файл на main (запись идёт только после удачного применения), а следующий удачный план любой строки — это план всего стека. Значит, после него облако снова как в файле. Но админка показывала последний запрос строки, пока по этой строке не будет нового запроса — то есть вечно.
- Пример — запрос пула `f758b39f` от 13.11: применение упало, файл не менялся, позже пул вернулся по файлу (сейчас 2 из 2 задач работают), а строка всё ещё «Не получилось».
- Исправление: проваленный запрос, после которого был любой удачный запрос, помечается `superseded`. Строка показывает своё прежнее положение, без «Не получилось». Положение «Авто» (`liveStates`) не меняется.
