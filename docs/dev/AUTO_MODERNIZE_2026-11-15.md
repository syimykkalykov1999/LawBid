## Что в этом PR (`claude/auto-modern`)
1. Шесть Python Lambda: `python3.12` → `python3.13` → `python3.14` (15.11, провайдер AWS 6.72), arm64. Тесты Lambda зелёные; на Linux они идут под Python 3.14.
2. Redis → Valkey одним переключателем: модуль `redis` (`engine`, `engine_version`, семейство групп параметров `valkey8`, `create_before_destroy`), стек и `envs/prod` (`redis_engine`, по умолчанию `redis`).
3. Проверка `scripts/ci/infra-modern.test.mjs`: все Python Lambda на 3.13 и arm64; Valkey включается одной переменной, по умолчанию прежний движок.

## Владельцу
1. Следующее обычное применение облака из админки обновит среду Lambda (короткое обновление функций, без простоя сервиса).
2. Valkey: после того как уменьшение Redis доказано, поставить в настройках Terraform `redis_engine = "valkey"` → применение с 2FA. AWS обещает без простоя.
   - Не проверено: принимает ли провайдер AWS 5.100 `engine = "valkey"` на плане. `validate` проходит только с движком по умолчанию.
   - Если план откажет — сначала обновить провайдер.
3. PostgreSQL 18 и провайдер AWS 6.x (для python3.14) — отдельные задачи по очереди, каждая со своей проверкой.
