Ветка `claude/speed-gaps-2`, по `docs/dev/SPEED_MATRIX_2026-11-09.md`. PR #872 (приложение/сайт: документы, лента дел, голосовые с Range, веб-кэш Drift) и #874 (админка: ленивые картинки с копиями, кэш в IndexedDB + дешёвый ETag, события вместо опроса, сторож perf-admin в CI) здесь не повторяются. ## 2. Что искали и где
- Стикеры: `sticker_widgets.dart:48-50` единственное место с `CachedNetworkImage` без `cacheKey`; `stableImageCacheKey` уже есть (`stable_network_image.dart:155`).
- Комментарии: `comment_widgets.dart:727` единственный вызов `addComment`; `CommentsNotifier.add/replace` уже были, не хватало `settle/remove`. Образцы: `pending_posts.dart`, `chat_media_outbox.dart`.
- Веб-голосовые: `voice_player.dart` ветка `kIsWeb`; `WebBlobStore` (`core/cache/web_blob_store.dart`) и `web_download_web.dart` (blob URL) уже были.
- Админка: `onMutate` — 0 вхождений до этой ветки; `react-window/virtuoso` — 0; `browser-image-compression` — 0. `support/composer.tsx` уже параллелит вложения.
- Сервер: `multipart.ts:12` порог 16 МиБ; `files.policy.ts` потолки по purpose; `app-settings.defaults.ts:82,290,436`.

## 3. Как у больших и почему так же у нас
- Instagram/Threads показывают комментарий сразу и убирают его при ошибке — так же здесь.
- Telegram Web / WhatsApp Web держат голосовые и медиа в хранилище браузера (IndexedDB/Cache Storage), не качают дважды — так же здесь (Cache Storage).
- Telegram/WhatsApp сжимают стикеры до 512 px на клиенте — админка теперь тоже.
- TanStack: оптимистичные мутации и виртуализация — их собственные документированные образцы, без своего кода.
