# Аудит лицензий и чужих брендов, 17.11.2026 (строка 232 списка владельца)

Это не юридическое заключение, а проверка всего, что мы поставляем и запускаем, с выводом по каждому пункту. Продолжение аудита [`docs/legal/LEGAL_RISK_AUDIT_2026-10-28.md`](../legal/LEGAL_RISK_AUDIT_2026-10-28.md). Указатель уведомлений: [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md).

## Коротко

- **В приложение, на сайт и в админку уходит только MIT / Apache-2.0 / BSD / ISC и шрифты OFL.** Исключение — Mediabunny (MPL-2.0, разрешение владельца 08.11). GPL, AGPL, LGPL в том, что получает пользователь, нет.
- **Исправлено:** пакет `buffers` 0.1.1 без всякой лицензии (на сервере, внутри `exceljs`) убран: `unzipper` поднят до 0.12.5 (MIT, последняя), он больше не тянет `binary` / `buffers` / старые `fstream` и `rimraf`.
- **Исправлено:** в спрятанном наборе для своих серверов (`infra/selfhost`) `redis:7-alpine` (Redis 7.4+ — RSAL/SSPL, не BSD) заменён на тот же Valkey 9.1.3 (BSD), что на проде.
- **Исправлено:** уведомления. В корне появился `THIRD_PARTY_NOTICES.md`; дописаны пропуски (пароли SecLists, шрифты Noto в PDF, серверные LGPL/EPL/FSL с ссылками на исходники, шрифты админки, нативные SDK телефона, CryptoSwift с обязательной строкой благодарности, шрифты и картинки приложения). У копии `flutter_secure_storage_web` не было файла LICENSE — добавлен (BSD-3, автор оригинала).
- **Исправлено:** приложение само кладёт в свой список лицензий шрифты и все разделы `apps/mobile/THIRD_PARTY_NOTICES.md` (`lib/core/licenses/bundled_licenses.dart`, тест рядом). Внешний вид не менялся.
- **Нужно слово владельца (внешний вид):** в приложении нет экрана «Лицензии открытого ПО». Всё нужное уже лежит внутри приложения, но по правилам Apple/Google и по обычаю (Telegram, WhatsApp, Instagram — «О программе → Лицензии») экран лучше показать: одна строка в настройках открывает стандартную страницу Flutter `showLicensePage`. Это уже было в аудите 28.10, пункт 4.
- **Бренды:** в текстах, которые видит пользователь (приложение, сайт, письма, пуши, магазины, юр. тексты), чужих названий нет, кроме кнопок «Поделиться в …» и слов поиска, которые пользователь не видит (разобрано 28.10). В подсказках админки снова появилось «как в WhatsApp / Instagram» (видит только владелец) — оставлено, риска нет.

## Бренды и чужие тексты

- Строки приложения (`lib/core/l10n`), переводы (85 языков), письма, пуши, юр. тексты (`apps/api/assets`), тексты магазинов (`docs/aso`), SEO (`scripts/seo`), веб-файлы: чужих названий нет. В переводах названия есть только в скрытых словах для поиска (`…kw`: «uber accident», «instagram hacked»), это описательное использование, пользователь их не видит.
- «Поделиться в WhatsApp / Telegram / Instagram / TikTok…» — значки FontAwesome Free, имена указывают, куда отправить ссылку; Instagram — одноцветный, как требуют правила бренда (исправлено 28.10).
- Подсказки админки (`flags/page.tsx`, `config/page.tsx`): «как в WhatsApp / Instagram / Telegram». Видит только владелец, это не реклама и не товар — оставлено.
- Описания в API (`openapi.json`, репозиторий открытый): «Telegram-style», «WhatsApp» как пояснение для разработчиков — допустимо.
- Чужих логотипов, скриншотов, звуков и картинок в `assets` нет: фото Unsplash с авторами, звуки — наши синтезированные тоны.
- Название функции «Reels» (знак Meta) — открытый вопрос из аудита 28.10, не трогал.
- Патенты: в коде нет известных запатентованных механизмов вне стандартов (видеокодеки H.264/AAC даёт ОС телефона и браузер со своими лицензиями; своих кодеков мы не поставляем).

- Полное дерево Gradle (все артефакты Maven) не собиралось: на диске около 8 ГБ, сборка Android не запускалась. Основные семейства перечислены по файлам плагинов.

- Сайт LawBidSite: исходников на этом компьютере нет (как и 28.10).
