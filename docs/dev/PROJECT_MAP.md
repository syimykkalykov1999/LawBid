## 1. Самые главные правила (подробно — AGENTS.md)
0. Берём готовое ЦЕЛИКОМ и не смешиваем со своим: ломается именно из‑за смеси нашего нерабочего кода с кусками чужого. Наш заменённый код удаляем, подключаем только по краям (наши экраны, вход, уведомления). Чужой код своими заплатками не «чиним».
1. Только копируем проверенный открытый код (MIT/Apache/BSD). Свой код — только если готового нигде нет И владелец прямо разрешил.
2. GPL/AGPL и код, требующий открыть наш, — не копировать; изучить и построить так же, без придумывания.
3. Каждый чужой файл — проверка на вирусы и опасные строки (отправка данных на чужие серверы, скрытый код, установочные скрипты).
4. Правила одинаковы для iPhone, Android, сайта, админки, сервера.
5. Внешний вид приложения не меняем без прямой просьбы владельца.
6. Лёгкость: телефон не греется, сервер не пропускает файлы через себя, кэш везде, качество как Instagram.
7. Экономия токенов: одна задача за раз, не больше 3–4 помощников, проверки — программами.
8. Честный отчёт: проверено / не проверено / сломано. Никаких «всё работает» без проверки.

## 2. Владелец
- Не программист. Отвечать по‑русски, коротко, простыми словами. Команды для него — блоками Run.
- Пароли и коды за него не вводить. Продакшн‑изменения (terraform apply, IAM, SSM, деплой Approve) нажимает он.
- Ждать, пока владелец договорит, и только потом начинать.

Звонки, полностью (аудио и видео; заблокированный экран на iPhone и Android; ответить, отклонить, сброс, завершить, пропущенный; аватарка и имя ЗВОНЯЩЕГО на системном экране и в уведомлении; значок идущего звонка; переподключение; микрофон, камера, динамик, смена камеры; маленькое окно; завершение без зависшего кадра).
