# Сверка по коду: нагрузка на сервер и базы, автоматический рост (2026-11-02)

Ответ ниже только по прочитанному коду и Terraform. Прод и AWS я не трогал; `terraform validate` локально не запускал (нет бинарника), это проверит CI.

## 4. Что нужно от владельца

1. Для авто-реплики: `db_replica_toggle = true` в `terraform.tfvars` прод-окружения и `terraform apply` (с Mac). Без этого авто-режим ничего не делает.
2. После apply политика сокетов `api_sockets` появится сама; цель 2500 можно поменять переменной `api_sockets_per_task` модуля `ecs` (0 = выкл).
3. Докачка #552: Terraform apply CORS (с Mac).
4. OpenSearch: когда тревога `db-slow` (запрос > 100 мс, обычно поиск) покажет необходимость, включить `opensearch_enabled` в админке «Масштаб», затем `search.engine` = shadow → engine.
5. Решения по миллиардной шкале (партиции `post_view_events`, `user_activity_days`): см. `SCALE_LIMITS_AUDIT_2026-10-23.md`.

## 5. Не сделано

- Автоудаление реплики и автосоздание OpenSearch (обоснование выше).
- Полный обход всех `findMany` на отсутствие `take`: сделан выборочно.
- Проверка планов запросов на реальных данных: нужен прод/замер 1M (тред «Аудит кода», A-6).
