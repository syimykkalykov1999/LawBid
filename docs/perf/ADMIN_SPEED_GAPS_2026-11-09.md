## Было / стало (замеры)

Запросы живых панелей за 5 минут — тест `apps/admin/src/lib/live-budget.test.ts` на настоящем QueryClient админки и таймерах TanStack (29 запросов с `livePoll()`):

| режим | запросов за 5 мин | в минуту |
|---|---|---|
| опрос раз в 60 с (было) | 145 | 29 |
| сокет, на сервере ничего не менялось (стало) | 0 | 0 |
| сокет, 2 изменения на сервере за 5 мин | 58 | 11,6 |

Списки `/admin/users`, `/admin/cases`, `/admin/audit-log` при повторном открытии без изменений: было — полный запрос списка (findMany 50 строк + аватарки) и Express считает ETag от тела (304 экономит байты, не базу); стало — один `MAX()` по индексу (≈ 1 мс) и 304 без тела. Размер тела первой страницы пользователей ≈ 20–30 КБ, журнала ≈ 25 КБ (см. колонку bytes `perf-admin.e2e-spec.ts`), при 304 — 0 байт тела.

Картинки: 13 из 13 `<img>` ленивые (было 3); там, где сервер делает копии (вложения поддержки, фото из жалоб, лайтбокс с источниками), браузер берёт 320 px для миниатюры вместо оригинала. Оценка: миниатюра 320 px ≈ 20–40 КБ против 2–5 МБ оригинала с телефона — в 50–100 раз меньше на миниатюру. Документы верификации (паспорта, лицензии) копий на сервере не имеют (обработчик делает их только для фото постов/дел/чатов, `file-scan.processor.ts`), поэтому для них пока только ленивая загрузка; делать копии документов — отдельное решение (качество сканов).

Перезагрузка страницы: было — все списки с нуля (каждый запрос ждёт сеть); стало — страница рисуется из IndexedDB сразу (0 сетевых запросов до первого кадра с данными), затем TanStack сверяет устаревшие запросы (304 от браузерного кэша, где тело не менялось). Замер «время до интерактивности» через browser perf API в этой ветке не снят: вход в админку требует живого 2FA, у помощника его нет — шаг владельца (DevTools → Performance → `domInteractive` до/после на любой странице-списке).

## Шаги владельца
- Terraform не нужен: адрес сокета берётся из `API_BASE_URL` (origin) и попадает в CSP сам; при другом хосте сокетов — переменная `ADMIN_SOCKET_ORIGIN` у админки.
- Выключатель на случай беды: Настройки → `realtime.admin_events_enabled` → Выкл (панель вернётся к опросу раз в минуту).
