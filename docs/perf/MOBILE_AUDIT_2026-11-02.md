## Исправлено в этом PR
- **Скачивание документов дела без докачки.** `CaseFileCache.download` делал `Dio().download` в `.part` и при обрыве начинал заново (на 1,3 Мбит/с PDF 10 МБ — ~1 минута впустую на каждый обрыв), через «голый» Dio без нативного стека. Теперь `ResumableDownload` (`core/files/resumable_download.dart`): `Range: bytes=N-` с остатком из `.part`, 200 вместо 206 → перезапись с нуля, 416 → одна перезапись, обрезанный поток не считается готовым файлом, две нажатия на один файл делят одну передачу. 4 теста.
