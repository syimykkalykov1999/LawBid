### Почему CloudWatch дороже оценки (по коду; разбивки по типам расхода у меня нет)

В Terraform: 102 блока `aws_cloudwatch_metric_alarm` (часть с `for_each`, то есть тревог больше), 3 составных, 37 фильтров метрик из логов (каждый создаёт платную пользовательскую метрику ≈ $0,30), плюс 14 метрик `LawBid/Runtime` из EMF (≈ $4,2), 1 дашборд, 9 лог-групп с хранением 30 дней (14 у Lambda-автомасштабов и journey). Тревоги ≈ $10–15, метрики ≈ $15, остальное — приём логов ($0,50/ГБ).

Что можно сократить без вреда пользователям (оценка, не измерено):
- 10 фильтров метрик, чьё имя в Terraform не используется ни тревогой, ни дашбордом (искал по имени): `cron_job_failed`, `search_latency`, `ws_connections`, `ws_going_away`, `business` (несколько метрик через `for_each`), `cf_realtime_egress`, `db_dead_tuple_ratio`, `db_txid_age`, `outbox_oldest_pending`, `db_table_health`. Часть может питать админку или Logs Insights по логу, а не по метрике, поэтому перед удалением нужна проверка. Выгода ≈ $3–5/мес.
- Хранение логов 30 → 14 дней на самой «шумной» группе API снижает только хранение (≈ $0,03/ГБ), а не приём, поэтому почти ничего не даст.
- Настоящий драйвер надо смотреть по типу расхода: Cost Explorer, фильтр сервис = CloudWatch, группировка по Usage Type (`DataProcessing-Bytes` = приём логов, `MetricMonitorUsage` = метрики, `AlarmMonitorUsage` = тревоги). Пока этого нет, резать вслепую не буду.

## Вывод

Реально «пустое» ядро ≈ $241: из них ≈ $170 — это то, что нельзя убрать без простоя или риска (серверы, NAT, ALB, IPv4, БД, Redis, WAF API). Дорогих забытых ресурсов в Terraform не нашёл. Возможная экономия без вреда пользователям небольшая: ≈ $5 (память worker после замера) и ≈ $8 (WAF на раздаче, на вкус владельца). Крупные кандидаты (NAT-инстанс ≈ $25, без Multi-AZ базы и реплики Redis ≈ $26) снижают надёжность, их решает владелец.

Не проверено: что реально создано в аккаунте вне Terraform (старые ручные ресурсы, неподключённые EIP, снимки, логи с вечным хранением). Это даст только Cost Explorer и `aws-inventory.yml` с Mac.
