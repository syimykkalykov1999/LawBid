# Этап 3: скорость и нагрузка (15.10.2026)

Всё из `plan/perf-cost-audit.md`, что реально нужно. Каждое изменение за флагом
или с безопасным откатом. Инфраструктура только как код, ничего не применялось.

## Что сделано и как откатить

| Что | Где | Как выключить / откатить |
|---|---|---|
| Сжатие ответов API (gzip/brotli, ответы от 1 КБ) | `app.setup.ts`, `responseCompression()` | `HTTP_COMPRESSION=false`; заголовок `X-No-Compression` на отдельный запрос |
| ETag и ответ 304 без тела | сервер: `app.setup.ts`; телефон: `core/cache/http_cache_interceptor.dart` | сервер `HTTP_ETAG=false`; сборка `--dart-define=ETAG_CACHE=false` |
| Таймаут, одна повторная попытка и «предохранитель» для Twilio, Bunny, FCM | `common/resilience/*` | откат коммита; предохранитель сам закрывается через минуту |
| Журнал медленных запросов к БД (только имя операции и время, без значений) | `prisma/slow-query.extension.ts` | `DB_SLOW_QUERY_MS=0` выключает, по умолчанию 300 мс |
| Курсорная пагинация отзывов (рейтинг, «полезные») и шаблонов; поиск уже был на курсоре | `common/pagination/ranked-cursor.ts` | старые числовые курсоры продолжают работать |
| Чистка `post_views` старше 365 дней (счётчик просмотров остаётся) | `storage/data-retention.service.ts` | настройка `storage.retention_post_views_days`, 0 = хранить всегда |
| Лимиты сокетов: пакет до 64 КБ, явные ping и connect таймауты | `realtime/realtime.gateway.ts` | откат коммита |
| Аватары и миниатюры: дисковый кэш и декодирование в нужном размере | `app_network_image.dart` | откат коммита |
| Ночное уменьшение серверов, ARM (Graviton), Spot для worker | `infra/modules/ecs`, `infra/modules/stack` | всё выключено по умолчанию: `night_scale_down`, `cpu_architecture`, `worker_spot` |

## Проверено, менять не пришлось

- Ключи идемпотентности: создание кейса и отклика требуют ключ на сервере, приложение его ставит; сообщения защищены по `clientMessageId`.
- GIN-индексы (`gin_trgm_ops`) на полях поиска есть: кейсы, посты, адвокаты, клиенты, теги, пользователи.
- Переводы по версии (`since=version`), пакетная отправка отчётов о вылетах и предзагрузка постов уже были.

## Замеры (один и тот же код, переключение флагов, локальный API)

Размер ответа в байтах:

| Запрос | до | после (gzip) | повторно (304) |
|---|---|---|---|
| `/feed?limit=12` | 38 532 | 6 008 | нет тега |
| `/practice-areas` | 70 930 | 18 306 | пустое тело, 7 мс |
| `/config/bootstrap` | 44 303 | 14 730 | пустое тело, 8,5 мс |
| `/reels?limit=20` | 14 722 | 3 049 | пустое тело, 17 мс |
| `/conversations` | 8 706 | 1 754 | пустое тело, 17 мс |
| `/notifications` | 5 532 | 1 725 | нет тега |

Задержка сервера в пределах шума (второй замер на свободной машине: лента 68 мс до и 74 мс после,
остальные запросы ±2–7 мс; небольшая добавка это расчёт ETag, сжатие идёт на лету и данные в сеть уходят быстрее).

Память телефона (эмулятор, debug-сборка, один сценарий: лента, «Моё», профиль, 2 прогона):
общая PSS 553,6 и 556,0 МБ до, 547,0 и 548,0 МБ после (около −8 МБ). На тестовых данных
картинки маленькие; на реальных больших фото выигрыш больше: фото 4000 px занимает около
64 МБ при декодировании, в аватаре 120 px около 57 КБ.
